2026-10-10 的火箭补强扫描了两季 `labels*`，并按活动 catalog／manifest 核验实际文件字节和 SHA256：2024–25 当前没有火箭标签；2025–26 有上述 3 场、36 个唯一现存视频路径，其中标准 `labels/` 28 段、`labels-batch-008/` 7 段、`labels-sample-001/` 1 段，0 个纯标签缺文件记录。这是现有素材的当场名单覆盖，不是两季全部比赛覆盖；不同视频路径仍可能含重叠画面，单独上传的官方训练素材未重复计数。

新增 `nbaPlayerId` 是官方 personId；`jersey`、姓名、出场状态分别保留来源说明与快照摘要。原 `PlayerGameRoster` 仍输出 `name:` 规范化姓名键，并未改成返回 NBA ID。实际调用验证了全部 79 行：60 行出场返回唯一候选、19 行 DNP 全部排除，包含 `0`／`00` 区分。未出现在官方 box-score 行中的 inactive 人员不按赛季表补造。

今晚确定具体比赛后，应显式选择对应 `gameId` 才会使用当场名单；没有比赛编号时仍可能走赛季名单。当前两季之外的场次、图像姓名识别准确率、实时模型调用和云端数据状态均不由本轮名单验证代表。原始响应、旧文件备份、重建脚本和验证证据存本机研究目录 `data/nba2k/research/rockets_20261010/game_rosters/`（工作区外层，未随本仓库提交）。
