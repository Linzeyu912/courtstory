# 工作台本地视频文件夹

把 MP4、MOV、MKV、WebM 或 AVI 放在此目录（也支持子文件夹），然后在工作台顶部打开「视频库 / 导入」，点击「刷新文件夹」。也可以在页面选择「导入视频」，文件会复制到这里。

首次使用视频时，分别选择 YOLO 检测器和跟踪器，再点击「处理并打开」。默认使用带「推荐」标记的篮球 YOLOv8n + BoT-SORT 外观续接；也可使用其他组合。处理完成后，同一视频和组合会复用已有结果。视频、各组合的人工草稿分别保存，详见[模型选择](../../engineering/docs/model-selection-layout.md)。

这里的视频只在本机使用，已被 Git 忽略。处理结果保存在仓库根目录的 `artifacts/player-review-imports/`，原文件保留。上传单文件上限 2 GB，更大的视频直接放入文件夹。相同内容会合并展示；同名不同内容导入时自动改名，不覆盖已有文件。

只有需要按团队规范共享的成片才另行登记到 `data/videos/`，参见[视频数据管理](../../docs/video-data-management.md)。本地导入不会自动上传 GitHub。
