# NBA 2024–25：100 段训练素材

拉取LFS成片后，打开 [index.html](index.html) 选择视频。可按球队或动作搜索，按相似战术组、完整程度筛选。[文字清单](INDEX.md)也能逐段定位视频。

共100段，含原首批3段；覆盖16场比赛、17支球队，合计838.553秒（约14分钟）。3段1080p，97段720p，单段约2.97–14.88秒。

## 标签与重复标记

每段文件夹含 MP4、README.md 和 labels.json。标签记录比赛阶段、美国比赛日期、北京时间日期、节次、比赛时钟、进攻与防守球队、动作描述、来源链接、原片裁切秒数、文件校验值和完整程度。

- 同一球权未重复收录；相似战术分为G01–G16组。
- `tactic_repeat`：是否有同类片段；`similar_to`：关联编号；`repeat_reason`：关联依据。
- [repeat-groups.json](repeat-groups.json)列出各组；[annotations.json](annotations.json)保留采集时的全部100段说明；[manifest.json](manifest.json)为统一资产清单。
- 14段保留完整球权，其余86段保留前场配合、推进、防守或二次进攻片段。
- 007、038、051、071的起始时钟被原转播图层遮住，记录为null；可见比赛时钟读数约±1秒。

## 画面与验证

保留正常速度的原转播画面、画幅、帧率、音轨、比分牌和水印；仅裁切及编码。标签描述可见动作，未核实球队内部战术名称。

100个MP4均通过全程解码检查、人工画面检查，100个文件哈希不同。详见[verification.json](verification.json)。原片与检查中间图片单独留在本机，不在本包内。

来源采集：2026-09-30；成片整理完成：2026-10-01，Asia/Shanghai。素材比赛均属于2024–25赛季，来源页面的上传日期可能更晚。
