# 球候选与球权关系：真实输入的小实验

2026-10-02，UTC。本轮只读既有候选，未重新调用视频模型。脚本为根目录 `object_probe.py`、`ball_selection_probe.py`、`evaluate_ball_challenges.py`；图片由 `visual_audit.py` 和 `render_ball_challenges.py` 从源视频解码。JSON各自保留来源路径与SHA。

三段E-BARD共815帧，模型输出359个篮球框，分布在340帧；475帧无篮球检测，原因未知。19帧各有两个候选。所有815个对应team-stable帧均不提供objects字段：上层需要另接同视频同PTS的对象通道，不能输出“球消失”。此统计不度量precision/recall。

|---|---|---|---|

第一轮假设：最高检测分数能够从多球候选中选出球。主动选择4个真实压力帧（005:4、117；006:242、330）作双AI视觉复核。另一AI先看raw后看overlay，根代理看过两者；都不是人类标注。4例相对选择一致，运动模糊仍有不确定性。最高分并按数组顺序打破平局的策略在3例与视觉判断不同：严格较高分误选2例，006:242平分按顺序误选1例，不能说低分胜高分。这是反例发现，不是75%总体误判率。

第二轮假设：近邻时序能消歧。固定最多前/后3帧内寻找单球候选，最近距离领先第二名至少该球框半对角线，作为建议；不修改raw，不输出自动纠错。本脚本未检查切镜，建议可能跨镜头，不能直接执行；需由下游另行检查镜头范围。结果见 `selection_results.json`。19个多球帧中因果建议16个，双侧一致建议10个；其准确率未知。

| 策略 | 4压力例中与AI相符 / 不符 / 弃权 | 额外证据等待 |
|---|---|---|
|最高分，平分按数组先后|1 / 3 / 0|0|
|最高分，平分弃权|1 / 2 / 1|0|
|只看前邻单球|3 / 0 / 1|0|
|前后单球选择一致|1 / 0 / 3|33–100ms，包括等待后决定弃权的情况|

双侧方法损失了3个AI认为可选的case，不是免费提高质量。005:4和006:242的后邻单球转而支持人体误检；其后续raw帧005:5和006:245亦已检查。时序支持可沿错误持续，不能把“多个相邻帧同意”当独立投票。只看前邻在这4例的表现不能外推，未使用独立保留集调参与测试。

第三个实证反例：004第104帧，球中心约(700,362)落在E-BARD T7（白衣19号）的框内，球分数0.521、球员分数0.879。98–108序列与局部放大显示球从右侧传入，在投影上穿过球员腿旁，没有手球接触证据。`ball_center inside bbox`可作为图像关系候选，不能变成持球事实。359个球候选中263个中心在至少一球员框内，其中37个同时在多个框内，这些只是歧义计数。

修订边界：本轮自动修复为0。可给review队列提供前后帧、备选框、等待时间与来源；不能用投票抹掉备选。球/篮筐是离地对象，不能套球场地面单应矩阵计算米制球轨迹。未建立真实球检测召回率、独立误修率或球权准确率。

验证：`test_object_probes.py` 5项通过，覆盖原生basketball枚举、空通道语义、冲突邻帧、有限前视和几何平局。JSON将人类验收指标保持null。`visual_labels.provisional.json`明确要求人工仲裁；本轮没有冒充已完成人类标注。

下一轮有价值假设：先获得与候选独立的少量可见球框和不可判定标签，再比较因果建议与双侧建议；不扩大无标签参数扫描。需要单独标注球是否可见、接触、飞行以及球员身份区间，避免用同一模型生成的pseudo-label自证正确。
