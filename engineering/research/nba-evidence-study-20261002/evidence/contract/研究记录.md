## 契约语义

1. **观察、轨道、P、真人分开。** 每个 detection observation 指到一个源数组项，T 使用 `clip:variant + local_id`。P1 在真实 metadata 中是 `model_candidate`，作用 0–142 帧并对应 team-stable T6；本研究没有人工身份源，`nba_identity=null`。真人身份字段预留 namespace / id / name / season，但任何伪造 human_reviewed 都拒绝。
2. **像素与球场分开。** 原始框和 pose 脚点只允许 image_px。005 第1帧右脚通过真实 courtToImage 的逆矩阵得到约 `(26.141, 12.407)`，只保存为 `court_projection_hypothesis` / `court_m_candidate`，接地未知、米制精度未验收；不是实际球员米制位置，不能用于真实速度或间距。
3. **时间轴实解码。** 原型逐帧解码 005（143 帧）与 LAL–MIN（267 帧）并核对源时间。LAL 第0帧 `pts_ticks=1536, time_base=1/12800, raw_time=0.120s, local_elapsed=0s`。源 time 已实证为容器 PTS 秒，不用 frame/fps 重建，也不把它偷换成片段经过时间。
4. **镜头状态诚实。** 当前库 sourceCuts 为空只表示“未声明切点”，不表示已经证实全段同镜头。`shot_segment` 是声明边界生成的区间，`cut_review_status=unknown`。切点版本改变后，跨切运动和旧参考传播失效；未被发现的真实切点仍可能漏阻断。
5. **未知与缺失分开。** team-stable 未提供 objects 是 `not_provided`；E-BARD 某帧没篮球框是 `not_detected_reason_unknown`。两者都不等于无球，也不能解释成球被遮挡；遮挡状态保持 unknown，不补隐藏坐标。
6. **每步可追溯。** source 保留仓库相对路径、源文件 SHA、格式版本；观察 / 绑定 / 标定保留 JSON Pointer、该值哈希及归一化记录版本。派生候选引用输入版本、cut 版本；模型及实现版本可沿 variant.meta_source 回到原始 metadata。SHA 只能验证字节一致，不能证明模型正确或来源可信。
7. **修订不能覆盖 raw。** `append_revision` 只接受 binding/calibration/cuts，含 old/new version、顺序、前一修订哈希、原因和 actor。基线观察不改写；有效视图另行计算失效状态。更新依赖版本号不能让旧 payload 复活，必须显式重新生成并校验。当前实现只失效，不自动重算修订后的 P 或场地派生物。
8. **分数不是概率。** score 保存原数值，语义固定 `uncalibrated_model_score`，probability 必须 null。derived_candidate 与 reviewed_fact 分开；本数据没有可靠人工复核适配器，reviewed_fact 当前全部拒绝。

## 真实例子与不能得出的结论

- 005 E-BARD T1 从帧0到帧1的框底中心图像位移约 `(-2.3666,+1.1833) px`、相隔 1/30 秒。这只是同一 T 标签下的图像变化，混有相机运动，不断言同一真人的运动。
- 005 帧2 的真实 `objects[1].kind="basketball"` 显式规范成 ball，原 kind 仍保留；球中心落在 T2 球员框内，图像中心至框距离为 0。输出低级 `ball_near_player`；零距离不是持球、接球、传球或投篮证据。研究阈值固定40像素，仅用于契约演示，未校准事件精度。
- 首次试读错误按 `kind="ball"` 统计，会漏掉实际 `basketball`。该结论已撤回并加入类别映射反例。按真实枚举完整扫描，004 / 005 / 006 分别有 74 / 78 / 207 条篮球框，覆盖 73 / 76 / 191 帧。框数不是正确球轨迹数，覆盖率不是准确率。
- 四项输出全是候选，没有真实姓名、持球、传球、投篮或真实速度输出。

## 验证与代价

基线 schema 与语义验证通过；22/22 受控反例按预期阻断，20 项反例仍能通过 JSON Schema，说明格式检查不够。独立审查发现的旧版本号续命、数值伪造和人物类别伪装球三项均已修复，并追加回归。语义 checker 核对当前源文件 SHA / Pointer、实值映射、variant 命名空间、PTS、区间、已知切点和依赖版本；四类派生数值会重新计算。

| 注入 | 实际阻断 | 会舍弃或延迟的内容 |
|---|---|---|
| P 绑定改版本 | `BINDING_VERSION_STALE` / `REVISION_REQUIRES_RECOMPUTE` | 依赖 P 的像素位置候选；raw、T运动和球框保留 |
| 场地参考改版本 | `CALIBRATION_VERSION_STALE` / `REVISION_REQUIRES_RECOMPUTE` | 依赖旧标定的球场投影；像素观察保留 |
| 把旧事实依赖号直接换成新号 | `REVISION_REQUIRES_RECOMPUTE` | 不允许未重算内容恢复可用 |
| 两版本同数字 T / feet 错接 | `CROSS_VARIANT_TRACK` / `FEET_VARIANT_FINGERPRINT` | 不做跨版本自动续接；需新关联证据 |
| 插入第1帧切点 | `CROSS_CUT` / `CALIBRATION_CROSSES_CUT` | 切点两侧运动及依赖旧镜头参考的投影 |
| LAL 把源0.120s改成0 | `PTS_MISMATCH` | 时序对不齐的观测和后续派生 |
| stale Pointer / 错文件SHA / raw改值 | `POINTER_HASH` / `SOURCE_HASH` / `RAW_VALUE_CHANGED` | 来源无法核实的输入；当前研究版保守拒绝整个有效视图 |
| 重哈希伪造 binding / matrix / 位移 | `BINDING_SOURCE_MISMATCH` / `CALIBRATION_SOURCE_MISMATCH` / `DERIVATION_MISMATCH` | 数值看似合法但不能由证据重算的派生 |
| 模型冒充人工 / proximity冒充持球 | `UNSUPPORTED_REVIEW` / `HIGH_LEVEL_EVENT_RULE_NOT_IMPLEMENTED` | 高层事件与真人措辞；候选仍可供人工复核 |
| 分数冒充概率 / 空来源 | `SCHEMA` | 无校准概率、无来源观察 |
| 非法外键 / 账本历史篡改 | `SEMANTIC_INPUT_ERROR` / `LEDGER_CHAIN` | 不返回部分成功视图，不让异常中断审计 |

两个受控修订后，8条 raw 归一化观察的整体哈希与修订前完全相等，4个历史候选记录仍在，只有 P 位置和球场投影的当前可用性变为 stale。像素 T 变化与低级球邻近仍可用。

## 未完成项
