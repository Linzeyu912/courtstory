## 保留的模型与比较设计

人物检测沿用 E-BARD YOLOv8n，跟踪使用既有 BoT-SORT / detector-native ReID 综合配置，704 输入。篮筐、篮球和裁判另用同一 E-BARD 权重独立保留图像候选；篮球不使用地面单应直接投影。所有源帧时间、原检测与各阶段候选独立保存。

球场使用同一个 Court48 权重。先按既有 640 输入处理，随后在观察到失败后新增 960 输入对照；逐秒同帧扫描均通过既有方向、四点布局与几何检查，不降低关键点置信门限。自动选择最接近片段中点的有效参照，并保持单次传播 ±20 秒限制。640 的参照偏早，因此部分片尾未进入这次操作范围，这与“已处理但视觉失效”分别统计。

脚部比较选择 YOLOv8s Pose 和 RTMW-l，固定每 10 帧取 1 帧，即完整 36 秒上的 108 帧 / 条件 / 模型。两模型共 864 次图像级采样，不称 4320 帧都推理过脚点。YOLO 独立识人后按 IoU 关联原框，RTMW 使用原框；分别为双踝与脚趾 / 脚跟中点，置信分数未跨模型校准。

## 结果：覆盖不是准确

| 条件 | 640 单参照有矩阵 | 960 单参照有矩阵 | 960 分段参照原始候选 | 排除接续冲突后实际可显示点 |
|---|---:|---:|---:|---:|
| 原片 | 901 / 1080 | 1049 / 1080 | 1079 / 1080（99.91%） | 960 / 1080（88.89%） |
| 降清晰度 / 模糊 / 压缩 | 365 / 1080 | 1050 / 1080 | 1080 / 1080（100%） | 960 / 1080（88.89%） |
| 数字缩放 / 平移 | 826 / 1080 | 1031 / 1080 | 1076 / 1080（99.63%） | 956 / 1080（88.52%） |
| 降低亮度 | 938 / 1080 | 1005 / 1080 | 1080 / 1080（100%） | 960 / 1080（88.89%） |

640 的处理范围分别为 961、751、901、991 帧，窗口外为 119、329、179、89 帧。960 的两种方案均覆盖全部 1080 帧处理范围。上表所有比例的分母仍是完整原片，不删除难帧；“有矩阵”不表示位置正确。

原片每秒扫描 36 次，640 只有 5 次初始化通过，960 为 26 次；模糊条件为 3 → 26 次，缩放条件为 4 → 25 次，变暗条件为 7 → 27 次。640 原片的被拒绝假设均因具名地面点不足，另有 3 个扫描时刻缺少可靠篮筐。扩大模型输入确实改善候选可见性，但不能独自解决跨全场的坐标问题。

### 单参照的跨半场漂移

960 单参照覆盖已达 93%–97%，反投影却显示：原先锁定右半场参照，在画面转到左半场后仍可能保留错误的外推位置。与同帧可接受的独立 Court48 点比较，原片在 120 个共同点上的差异 P95 为 361.60 px；这不是人类真值误差，但与肉眼可见的大幅场线错位一致。不能用高覆盖掩盖该问题。

### 分段参照实验与尚未通过的接续

实验按至少两个独立时刻的同侧场地证据形成左 / 右 / 左三组参照，在两组最后 / 最早可用时刻中点建立处理边界，前后各扩展 30 帧留下重叠区。原片边界为零基 210、705，参照在各窗口内按最接近中点的固定规则选择。

这些是**标定处理窗口，不是真实切镜**，不会切断球员跟踪或伪造新的球员身份。各窗口使用既有传播算法及门限；没有插值、轨迹平滑或填造脚点。所有原始窗口矩阵保留，正式工作台入口未改成此实验策略。

分段后，两侧半场场线明显改善。原片同样 120 个模型点的一致性差异中位数 / P95 为 5.60 / 27.26 px，对照单参照的 15.41 / 361.60 px；它仍不是独立定位精度。

但原片两处重叠区的球员同一图像点，经两个窗口矩阵投影后的差异中位数 / P95 分别为 **3.17 / 10.48 米**、**2.51 / 4.96 米**。其余增强条件也未通过接续检查。这揭示了半场局部标定外推到中场时的几何不一致，不能仅把两个高覆盖结果拼起来。

本轮探索性检查要求至少 3 个共同帧，投影差异中位数 ≤0.75 m 且 P95 ≤1.5 m；失败就在边界前后各 1 秒的重叠区暂不展示 2D，原始候选不删除。阈值不是米制真值验收标准，也不能证明重叠区外全部准确。当前实际显示覆盖 **88.52%–88.89%**，因此**这段新的全场素材尚未达到此前每段超过 90% 且尽量准确的验收目标**。

原片留空区间为零基 180–239、675–734，即 6–8 秒和 22.5–24.5 秒附近；具体各条件区间、原始传播失败及接续检查见本机 `summary.json`。报告视频明确标“接续冲突，2D 留空”，不把这些空白隐瞒成播放器问题。

## 脚部候选与增强一致性

| 条件 | YOLOv8s 双踝候选 | RTMW 双脚候选 |
|---|---:|---:|
| 原片 | 849 / 943（90.03%） | 915 / 943（97.03%） |
| 降清晰度 / 模糊 / 压缩 | 818 / 930（87.96%） | 901 / 930（96.88%） |
| 数字缩放 / 平移 | 849 / 939（90.42%） | 903 / 939（96.17%） |
| 降低亮度 | 839 / 940（89.26%） | 912 / 940（97.02%） |

分母为抽样帧里已跟踪的人物观测，可能包含误检；不是所有真实球员，也不是全部源帧。RTMW 候选较完整，但起跳 / 遮挡时是否接地尚无独立真值，本轮不宣布定位精度胜出。

以原片推算映射为参照，将同一个原图脚点施加已知增强变换后再投影，分段原始候选的坐标差异中位数 / P95：模糊 0.23 / 0.75 m，缩放 0.20 / 1.37 m，变暗 0.10 / 0.77 m。使用两边有矩阵且原片落点在场内、变换点仍在图内的配对观测；包含后来标为接续冲突的帧，不事后删掉坏段美化统计。这只说明相对一致性，双方可以一起错误，不能代替准确率。

## 结论与下一步

优先保留 E-BARD 检测与 RTMW 脚部候选，Court48 的 960 输入值得进一步验证；本次瓶颈是**左右半场与中场之间共享同一全场坐标的约束和接续**，继续增加检测模型不是目前证据支持的优先项。

下一步应在中场引入中线 / 中圈等独立具名地面约束，与两端禁区 / 底线共同优化全场几何，保留跨窗口的一致性拒绝机制；先量化接续误差，再谈平滑呈现。需要少量独立地面真值及更多不同场地 / 相机视频。960 和分段方案是在本片失败后探索得到，不能将它在同一片上的改善当作未见数据泛化证明。
