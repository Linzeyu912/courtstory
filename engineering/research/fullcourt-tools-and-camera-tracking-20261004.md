# 全场标定工具调研与接入建议

采集：2026-10-04，Asia/Shanghai。范围：广播篮球视频的连续摇摄、缩放、跨中场定位。以下分开记录上游能力、本地已验证事实和工程建议；本轮没有运行新外部模型的精度比赛。

## 本地问题已经定位

1. 工作台 `/api/court-calibrate` 调用 `court_calibration.calibrate_court`，镜头延续调用 `court_propagation.propagate_court`。它们围绕当前半场参照初始化、点线优化和地板运动传播。离线 `court_fullcourt.py` 的两端 / 中线全局联合求解尚未进入默认入口。因此“离线全场实验已做”不等于“工作台现在就在使用它”。
2. 半场内禁区点能很好贴合，不代表跨中场的尺度、方向和另一端坐标也受到了充分约束。只延续地板纹理关系会积累偏差；直接拼接两端独立标定也可能造成坐标跳变。
3. 原视频人物尾迹曾直接连接不同时刻的图像像素点。即使检测准确，也会把相机移动画进球员路线。本轮改为历史脚下点 → 历史帧球场矩阵 → 统一球场位置 → 当前帧画面；2D 和视频尾迹共用位置来源，详见[实现说明](../docs/court-relative-trajectories.md)。
4. 浏览器实查导入的 DAL–HOU 视频：0 秒有可用映射，13.4 秒无可用映射。这只是当时保存草稿的两个时刻抽查，不是全片覆盖统计，也不能判断其余时刻是否准确。

## 建议的实现路线

固定一张全场平面，左右篮端的物理坐标始终不变，队伍进攻方向另行存储。每帧估计的是相机相对这张球场的关系。半场、中场、另一半场只是“本帧看到模板的哪些部分”，不应各自重建原点。

1. **先接通已有全场候选的可复核入口。** 继续保留默认半场流程，将离线全场求解做成独立后端适配器；接收当前视频、裁剪时间映射、显式切镜和人工参照。原片与导入转码片的哈希不同，必须核对尺寸、时间戳和逐帧对应，不能按相同文件名复用矩阵。采用候选不得覆盖人工参照，也不得伪造人工已确认状态。
2. **增加可靠的全场绝对观测。** 用两端禁区、边线、中线、真实可见中圈圆弧约束同一个模板。先评估上述篮球语义分割组件，屏蔽人物、字幕和队徽；被遮挡的中圈允许缺失，禁止把队徽边缘当作圆弧。保留当前用户认可的边线细化算法，并对 005 第一帧作回归检查。
3. **联合约束相机运动。** 已有地板 SIFT / LK 作为相邻帧联系，语义场线和人工参考给绝对位置；用短窗口联合优化并定期重新定位，避免无限串联传播。对固定高位机位可试 BroadTrack 式 pan / tilt / zoom 与三脚架约束；数字裁切、镜头畸变、机位变化要另外建模，不假定所有广播镜头都符合单一 PTZ。
4. **单独处理失效与切镜。** 投影残差、观测空间覆盖、两参照一致性与相机变化共同决定质量；长时间失配时重新检测。不要冻结旧 H 或延长无观测插值来换取表面覆盖。硬切镜重启相机解，重入时重新确认篮端方向。

本地已有全场实验的原片候选覆盖是 1071/1080（99.17%），但这是[上一轮实验](court-fullcourt-20261004.md)，本轮未重跑；它仍有优化到迭代上限、降亮度中场偏移和缺少独立真值的问题，不能以此宣称已经满足准确性验收。

## 验收建议（尚未作为已达成结果）

- 保留用户提出的 >90% 有效帧覆盖，同时另报最长断档；分别统计半场、过中场、另一半场、返回。
- 留出不参与拟合的线段 / 交点，用投影像素误差核验贴合，按画面尺寸归一化；不能只报参与拟合点的误差。
- 选固定地面标志，测量其全场坐标随镜头移动的漂移；球员静止时也不应因摇摄产生跑动。
- 跑当前原片、已知缩放 / 平移、模糊、亮度变化，并补独立比赛 / 机位视频。增强片的一致性不等同于跨比赛泛化。
- 球员脚点误差与标定误差分开报告；双踝中点只是地面站位估计，腾空和遮挡仍可能偏离真实接地点。篮球空中位置继续单独处理。

近期优先项是“现有全场求解可复核接入 + 篮球语义场线小样本对照”，之后再评估相机参数化是否足以降低剩余漂移。这是本轮工程建议，尚无新模型胜出的实测结论。
