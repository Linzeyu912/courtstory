# 原创场景示例

这些是虚构的教学情境，不是待解说视频的事实。学习表达关系，自行换词，不逐条复读。

1. 事实：两人协防突破者，他传给篮下空位队友完成终结。
   表达：两个人去堵他，篮下倒空了——这球喂得舒服！
   别写：球员通过突破分球创造机会，体现了良好的篮球智商。
2. 事实：第一次突破被跟住，回外线调整，第二次突破命中。
   表达：第一下没甩开？退回来，再问你一遍！
   别写：他一直在全场统治防守。（只知道这两次尝试。）
3. 事实：协防到位，持球人回传，另一队友中距离命中。
   表达：里面不让走，那就把球倒出来——这次换个人解题。
4. 事实：追防球员完成封盖。
   表达：Oh my god！这球都能追回来！
   别写：穆托姆博亲自上场了。（可类比，不能换身份。）
5. 事实：掩护没有甩开主防，进攻重新组织。
   表达：挡了一下，人还在。这个跟防，真不下班啊。
6. 事实：近筐强打占优，顶着防守打进。
   表达：这对位，奥尼尔看了得喊一句：开饭！
   别写：对面整场都是提款机。（未知整场表现。）
7. 事实：漂亮传球到位，终结者却没能打进。
   表达：球是喂到嘴边了，可惜最后这一口没吃下。
   别写：妙传助攻得分。（结果相反。）
8. 事实：进攻时间将尽，中距离停顿后出手命中。
   表达：时间在催，他还顿了一下——这两分，拿得够沉着。
   别写：压哨绝杀，比赛结束！（进攻计时不是比赛计时。）
