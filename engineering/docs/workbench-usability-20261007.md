# 工作台可用性与人工接管

日期：2026-10-07，Asia/Shanghai。本轮处理用户实际使用的页面与 `/api/tactics-agent/jobs` 链路。改动仍在本机，未提交、未推送。执行依据见[本轮计划](plans/2026-10-07-workbench-usability-and-manual-fallback.md)。

## 现在怎样操作

1. **整段初稿**：进入「战术制作」，右侧「Agent 战术初稿」默认分析整段原视频。普通视频圈画不再要求先采用 2D。先看各段结果、参与者与未确认事项，再点击采用。
2. **重点球员圈**：点击工具后，在球员身上或脚下点击。首次未选范围时自动给出约 3 秒，可调整。自动贴脚失败会说明原因；可点「在刚才点击处放人工圈」，或直接切到「人工定位圈」重新定位。人工圈固定在画面中，不代表追踪结果。
3. **球场映射**：第二入口明确为可选，用于贴地标注和球场路线。先核对来源，再预览、采用；缺直播区间、人物、场地线或位置时有对应修补入口。只需暂停画圈或固定箭头，可直接进入战术制作。高级平滑与 AI 复核默认收起。
4. **失败后继续**：已完成的 Agent 阶段保留；可仅重试未完成部分，也可直接人工画图。跨人工阶段、无法安全追加的候选单列为“未加入画布”，由人核对。保存失败或版本变化不会假报成功。
5. **看清并修改标注**：采用后的新图形按参考画面建立讲解暂停点；主按钮“逐点检查”会停在这些画面，“连续原片”用于连续定位。采用按钮在候选详情前方；待核对说明和各段大图默认折叠，人数与阶段进度仍常显。

## 实现边界

- 对 24 秒以内的整段原视频最多分成两段分析，共用一轮 300 秒预算；准备耗时会扣减剩余模型调用时间，每个失败段最多自动修复一次。校验和预览收尾可能使实际总耗时超过 300 秒，这不是严格的实时墙钟承诺。
- V4 直接使用原视频像素与关键证据，按时长控制图片和轨迹输入。每段约每 3 秒一张、10.7 秒段通常 5 张，每段最多 16 个轨迹证据帧；参与者需求不因压缩而删除。未采到证据的人仍明确待确认。
- 每阶段列出持球、掩护、接应、无球和相关防守参与者。静态参与者可用位置圈；不确定者不计入已覆盖人数，也不靠一张图充当多人覆盖。
- 这些普通 Agent 图形在参考画面暂停展示，仍需人工核对。没有有效跟踪或球场映射时，不承诺连续贴地移动；不把模型猜测写成已确认身份。
- 已有手工稿可整段分析。采用以安全追加为原则，保留原阶段、原图形、动作和编排；跨阶段证据保留完整候选和原因，不擅自裁改路线。
- 每段尝试分别留存输入、输出和错误；浏览器保存轻量任务句柄，服务保存任务状态。刷新可恢复进度与候选，同源但草稿摘要或保存版本已变化时只允许查看旧候选，避免混入新稿。
- 模型结果已落盘而聚合预览尚未完成时，重启从已有输出恢复，不重新调用模型。服务已返回“采用”但页面未收到时，可在原版本匹配的前提下恢复同一采用结果。
