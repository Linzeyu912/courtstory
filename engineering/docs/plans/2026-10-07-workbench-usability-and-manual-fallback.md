# 工作台可用性与人工兜底修复

日期：2026-10-07，Asia/Shanghai。依据本聊天用户的实际使用反馈：视频最长约 24 秒，整段 Agent 初稿不稳定、多人标注未落实、重点球员圈点击无效、第二部分 2D 映射界面难懂。本轮优先解决可见操作与失败后可继续编辑的问题；2026-10-06 的整套工作流验收缺陷仍单独保留，不据此宣称已全部修复。

## 本轮出口

1. 从当前视频可直接发起整段初稿；短片普通暂停标注不要求先采用 2D。运行进度、已完成部分、失败原因与重试边界可见，生成失败时仍可手工制作。
2. 初稿覆盖相关进攻者、接应者、掩护者和防守者。每阶段列出有标注与证据不足的参与者；不能通过删除参与者、编造轨迹或增加无依据图形凑数量。
3. 点击重点球员圈后能进入明确的操作状态。未选时间段时给出可调整的初始范围；无法跟随球员时可明确选择在画面上人工放置固定圈。新增图形可见、可改、可撤销、可保存重载。
4. 2D 页面先说明用途与可跳过条件，再呈现来源核对、结果预览和采用。缺标定、缺身份或缺位置时提供能定位到具体修补位置的按钮；高级设置默认折叠。

## 人工接管规则

| 阶段 | 自动结果不足时 | 人工结果如何保留 |
| --- | --- | --- |
| 人物与位置核对 | 返回原视频选择人物、修正当前帧或明确留下缺口 | 保留原检测与人工修改，支持撤销 |
| 球场映射 | 说明何时需要映射；可去标定／补点，也可直接进入视频标注 | 未采用的预览不覆盖当前准备结果 |
| Agent 初稿 | 展示具体失败阶段；保留可用阶段，允许仅重试失败部分或继续手工 | 采用前为候选，已有人工内容不被自动覆盖 |
| 圈、路线与讲解点 | 无法自动绑定时明确选择人工定位，不静默失效 | 图形保留人工来源、适用帧段与可编辑属性 |
| 保存与交付 | 冲突和失败显示原因，当前草稿继续可编辑 | 不把失败当成功，不覆盖其他版本或原片 |

## 页面方向

战术制作：

```text
原视频与图形预览
整段 Agent 初稿 → 分段进度／参与者覆盖 → 预览并采用
                         ↓ 失败
               重试失败部分／继续手工标注
人工工具：重点圈、路线、讲解点；显示当前帧段和放置状态
```

2D 球场准备：

```text
用途：让球场路线和贴地图形获得球场坐标
只需暂停圈画？直接去战术制作
来源核对 → 查看球场预览 → 采用并保存
缺项修补入口              高级平滑／Agent（折叠）
```
