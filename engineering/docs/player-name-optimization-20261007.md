## 原先未知过多的原因

v3 的 64 个区间中有 28 段根本没有送入模型的证据。固定均匀采样错过清晰背号，拥挤框没有明确目标上下文，前景球员和裁判号码会污染读数。未知队服字样也曾被错误当作另一个球队。其次，既有 `ai_visual_reference` 关联不是人工真值；遮挡后 P2/P5、P1/P6、P7/P9 有临时 T 接错人的情况，不能沿用整条旧关联。

T9 历史球队颜色与当前白色球衣不同，追踪器会留下 `identity_review_required`。新帧的 `color_conflict` 可能恢复为 false，旧复核状态仍为 true，姓名取证错误跳过了大量实际球员帧。源记录保留；姓名模块只允许重新视觉核对这种历史颜色风险，独立裁判／角色风险仍排除。

模型连接失败也是另一种原因，必须与看不清号码分开。首轮完整 v4 的十人运行中，四名球员请求未成功；这不是四名球员没有可读号码。测试使用 `.env` 的 Qwen Token Plan，无按量 Key 回退。后续进程显式使用本机已有 HTTP 代理，有限重试只针对网络错误，不改全局设置。安全错误分类只保存固定类别、异常类型和数字 errno／HTTP code，不保存密钥或请求头。

## 代码处理

- 每人先在实际源图中按清晰度、遮挡与时间分散度选帧；上下文青色框指向目标，旁边放大同一目标身体。每人首轮最多八图、补看四图。明确修正窗和指定源帧优先进入首轮；难读修正窗优先获得同人比较补看。
- 球衣号码和球队文字来自实际视觉输出，姓名由比赛名单唯一匹配。未知字样不否定已知比赛上下文；名单不支持的数字保留为读数问题，不当作另一身份的可靠证明。
- 通过真实清晰参考帧建立唯一 P 身份。离线 `apply_reference_slot_identities` 只分析实际证据，不用诊断文件里的预设姓名填结果。外来身份若有两份明确目标读数且存在唯一真实参考 P，有限路由至该 P；不足则释放该段旧 AI 错绑，保留未知。
- `machinePlayerProfile` 的姓名状态和 `machineIdentityBindings` 的位置关联分开。机器结果仍不是人工逐帧真值；profile 不授权未知 T 或整片传播。人工选择与确认优先。
- 新有限修正可以覆盖同源旧机器关联。同帧竞争仅处理重叠区间，清晰尾段继续保留。合框切换边界可据源帧复核保守排除；排除不会生成新姓名或位置。
- 网页和视频复用脚底标签布局，保留固定 P 与真实姓名，画面边缘夹紧、拥挤标签分行。显示开关独立于全员识别与追踪。

## 试验与来源

输入仍为官方001的独立副本，比赛为 DAL/HOU、2025-26、`0022500701`。名单来自 [NBA 官方终场统计](https://statsdmz.nba.com/pdfs/20260131/20260131_DALHOU.pdf)，来源与采集记录见 [比赛名单](../../data/player-rosters/README.md)。视频 SHA、跟踪版本和指纹逐项匹配后才应用结果。

`research/vision/player-name-identity-20261007/optimization-probe.py` 记录真实 HTTP 调用、原帧证据及所有失败，诊断只向模型提供帧号和待核 T 区间。`merge-results.py` 合并同源完整输入的已保存复测，保留组件 job 溯源，并给新分析分配新的 jobId/sourceKey。`full-tracking.mjs` 使用实际工程消费与轨迹函数生成回放快照，`full-tracking.py` 保留原片源 PTS 和原声。

中间 `v4-ten-names` 已有十名不同且唯一的源图参考 profile：Amen Thompson、Jabari Smith Jr.、Tari Eason、Alperen Sengun、Kevin Durant、Max Christie、Daniel Gafford、Klay Thompson、Cooper Flagg、Naji Marshall。但该轮 Durant/Flagg 的姓名位置覆盖仍低，属于中间结果；其后的定向复测与边界处理以最终产物为准。

覆盖率计算为“有实际显示位置且可采用姓名的帧／有实际显示位置的帧”，不等于准确率。没有独立人类逐帧真值，不宣称 100% 准确。真实脚底接地点精度和长镜头换人仍需另行评估。模型曾在低分辨率背部框幻读姓氏；姓名使用唯一名单映射，不采用模型直接猜的人名。

本样例通过 AI 原图复核选择清晰参照帧和疑似错接窗口，再让实际模型读取号码／比较目标。它证明这段样例的改进，不保证任意未复核比赛都能一键达到相同覆盖。P10一轮补看曾幻称青框目标为裁判，原图表明目标是蓝衣球员；已拒绝该角色读数，保留先前可靠姓名，没有删除球员。修正窗内的弱目标图不能挤掉修正窗外的清晰参考；按frame/T去重，重复图不计独立投票。

合并复测时保留同源先前有效的有限正证据；新一轮未查看的区间或连接失败不会直接否定旧结果。新的实际反证仍按局部冲突和保守源图边界处理。新分析分配新的jobId/sourceKey，避免采用过raw结果的浏览器草稿因幂等保护跳过新分析。部分模型请求失败的ready任务不会永远复用失败缓存；用户再次发起可以得到新的任务，已有结果保留。
