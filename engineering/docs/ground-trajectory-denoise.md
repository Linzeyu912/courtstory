# 单球员 2D 轨迹去噪

`engineering/scripts/ground_trajectory_denoise.py` 提供轻量、无第三方依赖的单人轨迹函数。输入是一人按时间排列的点，按真实 `time` 做居中局部二次回归；不填空值、不跨缺口或切镜拟合，并把 `locked: true` 的点保持原值。明显孤立的大跳点先用邻点弦线修复，再参与平滑。默认用每侧约 0.08 秒的较宽邻域估计方向，并要求折返点两侧各有至少 0.12 米位移才缩短平滑窗；静止微抖不会被当成转弯。回归居中，不引入单向滤波的相位延迟。可用 `config={"turn_mode": "adjacent"}` 复现旧版逐帧相邻向量规则。

```python
from ground_trajectory_denoise import denoise_player

result = denoise_player(points, anchors=ground_anchors, cuts=[5], config={"profile": "balanced"})
smoothed_points = result["points"]
diagnostics = result["diagnostics"]
```

每个点至少包含 `frame`, `time`, `x`, `y`；原字段（包括 `source`、`locked`、`breakBefore`）都会保留。输出的 `x/y` 是处理后坐标，`rawX/rawY` 是输入坐标，`displacement` 以场地坐标单位计，`method` 与 `processedState` 说明处理状态。空值仍为空值。`cuts` 中的帧和点上的 `breakBefore: true` 都表示从该帧开始新段，可用于显式镜头切换或跟踪绑定变更。少于 `min_smoothing_points` 个有效样本的短段默认不做多项式平滑（默认值 7）；满足现有大幅孤立异常与邻点弦线条件时，仍可只修复该异常。对于绑定变更，断开只防止跨界平滑，不会改身份、移动边界点去强接，边界跳变仍应人工复核。`anchors` 接受 `frame/x/y` 对象，可直接传入 Qwen 候选里的球场锚点；它们以高权重参与拟合但不强制固定，`diagnostics.anchorReview` 同时列出输入和输出距锚点的距离，方便发现候选锚点可能不准。人工锁点不移动，仍保留其来源字段。

参数档位为：

| profile | 默认时间窗 | 单点最大平滑位移 | 孤立跳点最小阈值 |
|---|---:|---:|---:|
| `conservative` | 0.10 秒 | 0.55 米 | 1.8 米 |
| `balanced` | 0.16 秒 | 1.0 米 | 1.25 米 |
| `strong` | 0.24 秒 | 1.6 米 | 1.0 米 |

档位都处理了整段有效轨迹；最大位移限制仅限制常规平滑，极端孤立跳点会直接修复，不能让其余留成一个大尖峰。需要固定个别值时，可在 `config` 传入相同键覆盖默认档位。

此抽查没有修改 Qwen 结果、身份映射或标定，也没有声称运行已经结束。

P9 的困难转向 frame 917 已确认偏差来自去噪：保存的 `raw` 与 `refined` 坐标相同（约 `(6.134, 2.109)`），像素回投约 `(1291.4, 532.5)`；暂态 `points` 被平滑到 `(6.047, 1.616)`，回投约 `(1292.8, 517.9)`。因此相对该视觉参考的 19.5 → 32.9 像素误差变化是去噪造成的，不是 Qwen 重定位造成的。当前宏邻域复算也未解决这个具体点，最终应以逐帧复核处理。

## 001 原始轨迹参数复核

2026-10-07（America/New_York）依据冻结 001 raw、固定的 track binding 边界与 12 个可比较数值像素参考，另外试算了用户指定的 `window_seconds` 0.08 / 0.10 秒、`max_displacement` 0.25 / 0.40 米、`turn_cosine_threshold` 0.6 / 0.85 八种组合。输入不使用 Qwen 锚点；参考仍是独立 AI 视觉候选，不是真值。逐组数据保存在本机忽略目录 `artifacts/qwen-parallel-20261007/denoise-qa/single-player-001-parameter-sweep.json`。所有试算都应用默认 `min_smoothing_points=7`。

比较重点：原始二阶差分 RMS 为 0.230 米/帧²。最弱滤波组合（0.08 秒 / 0.25 米 / 0.85）降至 0.167，平均 / P95 移动 0.022 / 0.072 米，路径长度保留 77.1%；较强组合（0.10 秒 / 0.40 米 / 0.6）降至 0.109，平均 / P95 移动 0.033 / 0.100 米，路径长度保留 68.8%。各组合 12 个像素参考的平均误差从 12.1 像素变为 11.9–12.6 像素，落入不确定度范围的数量仍是 3/12；不足以据此调整全局平滑默认值。较弱组合是可供其他视频复核的保守候选，而非已确认精度更高的参数。0.6 与 0.85 阈值整体指标接近，当前证据没有证明提高阈值有益。

P9 frame 917 的冻结绑定使其所在有效段只有 frame 914–918 五个样本：frame 913 是上一跟踪 ID，frame 919 缺失，frame 920 起又是另一跟踪 ID。raw 局部夹角为 146.7°，也就是约 33°方向变化；旧平滑输出把它压到约 10–21°，但 5 点段没有足够对称邻域判断这个变化是转向还是框抖动。固定图像点 `(1300, 550)` 在 914–918 各帧的 `toCourt` 结果仅约漂移 0.065 米（x）和 0.019 米（y）；底部框点本身在 916→917→918 变化为 `[1302, 501]→[1291, 533]→[1282, 521]` 像素。现有证据更支持在短段保留原轨迹、交由画面复核，而非用更高 turn threshold 或更小位移上限强行追随单个视觉参考。默认仅增加短段保护，不据这些像素参考调整 profile 的窗口或位移默认值。
