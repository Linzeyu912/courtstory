## 布局方案

视频、叠加标注、逐帧播放控件和时间轴作为一个固定工作区域。视频保留完整比例；高度随视口缩放，时间轴不被视频挤出屏幕。右侧上部显示当前阶段的解说、标注属性、候选或成片设置，下部保留 Agent 入口。顶部保留保存、撤销和工作阶段。

时间轴用原片、解说、标注三行表达同一时间位置，单一播放头定位；标注区间两端为时长控制，右侧仍保留开始帧和结束帧数字输入。时间轴是拟议交互，本轮仅展示静态状态。

常用属性直接可见；高级坐标、冻结动画、模型设置、来源和导出以入口保留，后续拟在右侧原位替换内容或浮层打开，不向页面下方无限展开。长解说与候选按节点上一项／下一项切换；更多标注拟分页或按当前时间段过滤，当前图片展示 3 项示例，不代表已完成任意数量内容的实现。

成片预览复用主视频区域，实际生成成片的时间轴应以成片时长为准，冻结与配音可能改变总长。图片中的状态、解说、图形与时间数据只用于布局核对，不是后端生成或战术准确性验收。
