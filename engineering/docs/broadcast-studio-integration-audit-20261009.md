## 需要业务适配的具体缺口

1. **文字图形格式不兼容。** 样稿允许 `type: text`，正式 `tactics-annotations.mjs` 的类型校验目前仅接受 route/screen/spotlight/position。保留新 UI 文字工具时，需要补齐正式文档校验、保存、预览及成片渲染的支持；不能声称现有 API 已直接支持。文字标注与解说字幕分别处理。
2. **画布坐标与示例限制。** 样稿点选和拖动按 1920×1080 计算，逐帧按 30fps，缩略图固定为八张示例图。接入时必须建立与实际素材尺寸、帧时间和正式渲染一致的转换，其他视频不得显示示例缩略图。
3. **输入框含义。** 当前“这一回合，你想讲什么？”按钮实际只是加画面文字。正式界面应将解说编辑、绘图目标和人工文字标注分开，不让同一个发送操作隐式改变含义。
4. **草稿与任务上下文。** 当前演示缓存不能替代正式草稿。换视频/检测版本时保存并隔离上下文，迟到响应不回填。换端口/域名会隔离浏览器存储，须支持明确的旧稿接续方式。
5. **版本传播。** 保存新解说后，旧绘图依据可能失效；改图形/姓名/口吻后，旧成片需显示过期。保留人工修改并提示核对，不静默丢弃或自动覆盖。
6. **素材声音。** 样稿原视频和预览均设 muted，标签写死“无声片段”。正式素材的声音状态与配音结果必须真实可控。

## 页面组织与实施次序

- 保留样稿外壳、视频区、底部时间轴和右侧面板；战术区增加“解说 / 绘图”阶段入口。解说阶段显示逐句编辑，绘图阶段显示助手与所选图形属性。
- 顶部只保留当前工作区的主要操作，例如保存、预览或生成成片；取消仅任务执行时出现，采用仅有候选时出现，旋转仅选中相关图形时出现。原有高级编排、旧 Agent、数据备份仍有入口。
- 先接真实素材/播放器/共享上下文，再完成解说保存→绘图采用与保存→联合成片，随后补齐球员与辅助工具并核销功能清单。必要的文字图形兼容补齐属于迁移范围。
