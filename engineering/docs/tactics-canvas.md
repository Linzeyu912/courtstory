# 战术画布：按画面完成标注

本轮需求（2026-10-03，Asia/Shanghai）：用户需要明确的创作入口，能够直接修改或手工添加路线、放置挡拆标记、给重点球员加脚底圈。路线是对跑位的概括，可以由 Agent 或人工提炼起点、主要转向和终点，不必逐点复制机器轨迹。

## 操作流程

1. 选择阶段，暂停到要讲解的画面。关联球员是可选项；没有识别结果也能新建画布并手工标注。
2. 点击画面上方的工具：
   - **选择 / 修改**：点选已有标注，拖动控制点。选中操作条紧邻视频，可直接删除选中图形；`Delete` / `Backspace` 也可删除，输入框内按键仍用于编辑文字。
   - **画路线**：在视频中依次点起点、转向点和终点，再完成绘制。少量控制点生成平滑大箭头；创建不依赖检测器是否生成连续路线。
   - **挡拆标记**：在掩护发生的位置点击放置。选中后拖动旋转手柄可自由调整方向；视频旁的左转 / 右转按钮每次调整 15°，属性面板保留精确角度输入。拖动标记主体调整位置。
   - **重点球员圈**：在球员脚下放置椭圆，绑定球员后随可用脚点移动，可修正位置。
3. 预览阶段，检查路线方向和持续时间。播放时路线只显示尚未走完的部分；编辑控制点不会作为球员标签显示。
4. 使用撤销恢复操作；点击保存写入本机。自动草稿和手动保存状态分别显示。再次打开后可以继续修改。

旋转松手后才提交一次修改，因此一次撤销能回到拖动前的方向。播放、跳帧或切换阶段会取消尚未完成的旋转。删除后可用撤销恢复图形；取消选择只收起选中操作，不删除内容。

画面上的操作提示应随工具、已点击点数和选中对象变化。未完成的绘制可取消；播放、切换阶段或加载另一份草稿时不得把旧手势提交到新画面。

## 界面组织

- 主区：阶段、四个画布工具、当前操作提示、视频、对象列表和当前对象属性。
- 阶段设置、动作审核和来源信息折叠保留。识别路线仅作为可选参考，已有来源路线修正仍可从高级区进入。
- 战术模式保留紧凑的视频选择，不展示检测器和跟踪器配置；模型处理仍由视频处理 / 数据核对入口承担。
- 视频内不增加球员姓名、编号或操作说明文字。脚底圈是独立强调标记，不是路线末端的落点圈。

## 数据与边界

手绘图形进入独立的 `annotations` 字段，与既有 `presentation` 修正兼容；不修改原始 `review`、人物关联或动作审核结论。完整 JSON 和本机保存保留这些图形。

有球场映射时采用地面坐标随当前镜头投影。未校准时仍可直接在当前冻结画面标注，但应明确其只适用于该参考帧；不能将屏幕贴图宣称为随镜头的地面真值。重点球员圈跟随可用的对应球员位置，不得借用其他球员位置补缺口。

阶段或来源变化导致标注过期时保留原记录、说明原因，不悄悄应用到其他阶段。既有冻结报告的实际导出范围需在界面说明，不能把 JSON 保存称为视频烧录导出。
