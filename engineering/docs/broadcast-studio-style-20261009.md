## 定位与骨架

NBA 官网式的白天转播演播室：平面、哑光。黑白是主色，灰色负责过渡与分隔，红色保留品牌和重要状态点缀。用户进一步明确：普通文字按钮、链接和页签保持黑白，蓝色只留给复选勾等小型状态控件；原有红色点缀要保留。双行顶栏承担工作区导航，取消永久左侧流程导航；正文里的画面说明是可收展的内容模块。

- 第一行 56px，只呈现品牌：左上角使用球缝清晰的篮球线条标记与 COURTSIDE AGENT 字样；其余近黑区域只放两组灰色粗线局部图案，一组篮球外沿与单道球缝、一组球场边角，中间保留大片空白，不拼出完整篮球或完整球场。
- 第二行 44px，白底、`#D0D3D8` 下边线与极轻阴影。LIVE DESK 是工作台分区名，不代表素材正在直播；「球员标定、战术制作、成片」三个工作流入口集中在这一行，球场映射移到右侧「归档工具」，选中项下方为 4px 深色线。
- 工作区内部页签回到内容区：球员的处理步骤与画面说明／工具收展放在正文工具行，战术的「视频标注／解说配音」保留在战术面板内。「打开视频，人工制作」移到素材工具栏，与识别导入并列；本地工作台标签位于正文状态行。
- 正文 `#F5F5F5`，桌面上下留白 16px、左右 24px。球员工作区展开两侧内容模块时为 280px／自适应／340px 三栏，间距 16px。收展工具继续使用原按钮。
- 战术区保留视频／属性布局，属性列 340px；不同功能沿用各自必要的结构。1050px 以下按内容收拢，900px 以下视频与工具纵向排列，760px 以下页面纵向滚动。窄屏白栏隐藏分区字标，为三个工作流入口及归档菜单留足空间，必要时可横向滚动；内部工具行允许换行。
- 回放页同步使用品牌黑栏与灰色装饰，第二行保留回放分区说明和返回工作台链接。

## 色彩系统

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 近黑 | `#111214` | 全局栏、模块标签、真实数据块、正文 |
| 白 | `#FFFFFF` | 分区栏、内容卡、黑底文字、滑块圆点 |
| 页面浅灰 | `#F5F5F5` | 正文背景与轻量辅助区域 |
| 次要文字 | `#5E636B` | 浅底说明、时间说明 |
| 内容边线 | `#E3E5E8` | 卡片与分隔线 |
| 控件边线 | `#CDD0D5` | 表单、按钮 |
| NBA 蓝 | `#1D428A` | 复选框／单选框的小型选择标记 |
| NBA 红 | `#C8102E` | 重要状态、播放头、黑色引导卡顶边 |
| 亮红 | `#E5334F` | 黑底上大号 AGENT 品牌字 |
| 选中浅灰 | `#F2F2F2` | 当前选中或正在编辑的区域，配黑边 |
| 黑底灰字 | `#A4A8AF` | 数据标签及黑色引导卡说明 |
| 木地板 | `#D9A86C` | 球场内容 |
| 篮球橙棕 | `#B85A1E` | 球场内容中的球员／篮球示意 |

黑白建立页面与内容层级，也用于普通文字交互；灰色用于背景过渡、边框、次要文字和装饰。红色保留 AGENT 品牌字、错误／危险提醒、播放头及引导卡顶边，不扩展为普通按钮的底色。蓝色不用于普通按钮、链接、页签文字、焦点框或装饰弧线。橙棕、木色不用于界面导航。实际录像、球员分组及蓝／绿／黄／红／灰审核状态保留业务含义，避免主题更换造成误读。

蓝红色值来自用户提供的近似设计色，不声称来自 NBA 品牌指南。2026-10-10 实际检查 NBA 官网后，正文采用相同的 Roboto 字体家族；展示标题使用开源近似款 Roboto Condensed，不声称是官网的 Knockout Wide。

## 字体、形状与质感

- Roboto：正文和操作文字，中文回退 Noto Sans SC／系统黑体。正文基准 14px，紧凑操作控件 12–13px；按钮 600、正文 400、草稿 500，普通页签 400、当前页签 600。
- LIVE DESK 按用户最新要求恢复 Barlow Condensed Bold Italic 的轻微倾斜；Roboto Condensed 用于 REPLAY DESK 和大号数据的直立窄体，避免把所有展示文字设为斜体。品牌 COURTSIDE AGENT 单独保留已认可的 Barlow Condensed Bold Italic 外形与红色 AGENT。
- 时间码与数据使用 Roboto 的等宽数字；英文小标签约 11px、字距约 0.04em。原 IBM Plex Sans、JetBrains Mono 资产保留，但当前主题不再将它们用作正文／标签默认字体。
- 内容卡 4px 圆角、1px 边框；普通按钮约 3px 圆角。顶栏只保留品牌，不再放胶囊操作按钮。无玻璃、渐变、发光或卡片投影，只有白色分区栏下有极轻阴影。
- 键盘聚焦使用 2px 黑色轮廓；保留原按钮禁用状态、标签页方向键与 Home／End 操作。减少动态效果设置继续生效。

字体在本地打包，运行不依赖外部 CDN。来源锁定 Google Fonts 提交 `2eb0b48d5f760f62e286216f0859a8c540dbc1bd`；本轮新增 Roboto 与 Roboto Condensed 的拉丁字符 WOFF2 子集及 OFL 许可证，原四个字体二进制保持。许可证、子集、派生内部名称及摘要见[资源说明](../tools/player-review/broadcast-studio/README.md)。

## 组件应用

**模块标签：** 黑底白字、右端斜切；保留已有形状，移除静态标题上的蓝色。用于模块标题，不切割交互控件。编号、时间说明和普通提示同样优先使用黑灰色。

**交互用色：** 主按钮黑底白字，次按钮白底黑字。有按钮框、底色或独立块面的控件使用块面的边框／底色反馈，文字不加下划线；没有独立块面的纯文字链接才在悬停时显示字体下划线，移开消失，文字不变蓝。表单使用白／浅灰底、黑字和灰边；下拉选中项声明为黑底白字，实际原生菜单细节仍由运行平台绘制。选中工具、可编辑卡片与时间区间使用浅灰底／黑边；复选勾保留蓝色。滑块圆点为白色、2px 黑边，轨道灰色。

**导航反馈：** 工作流、处理步骤和战术内部页签都有完整块面，统一在整块底部显示黑线，字体始终不加下划线。未选中项悬停时显示自身的 4px 底边，移开即消失；已选项的底部标记始终保留。底边预留固定宽度，只切换颜色，不通过增减尺寸或伸缩伪元素制造悬停动画。只有真实点击或键盘选择改变时，共享选中标记才在 180ms 内移动。尺寸、字体加载或隐藏面板恢复只直接对齐；重复状态与相同几何值不写回样式，位置保留两位小数以过滤亚像素噪声。位置读取真实 `aria-current` / `aria-selected`，不干预工作区守卫和业务选择；减少动态效果时关闭过渡。

**白卡与黑色数据块：** 画面、工具、解说稿、弹窗使用白卡。已有真实计数使用黑底大数字和浅灰标签；不补造节奏、效率、比分等缺少数据来源的指标。

**篮球标记与球场装饰：** 左上角白色篮球使用圆形外轮廓、横竖球缝和两侧弧形球缝；两条弧线与中线拉开，避免小尺寸下交汇成一团。标记为 40 × 40 的 SVG、2px 圆头线条，实际显示 30 × 30，沿用轻微旋转。顶栏装饰继续只放两组，篮球轮廓半径由 116px 放大至 260px，灰线由 5px 加粗到 8px；只露出外沿与单道球缝，球场只留一个边角，去掉原先叠加的圆圈。保持 `#757A82`、32% 不透明度，上下裁切，避开品牌并拉开间距。装饰不响应点击；作为共享 CSS 内嵌 SVG 供工作台与回放页使用。数据块角落保留低对比图案。黑色空画布引导卡使用红色顶边和灰色弧线，按钮继续执行原有「建立画布」操作。实际顶栏见[本轮截图](images/nba-ui-20261009/header-basketball-detail-20261010.jpg)。

**战术与解说：** 保留真实视频、木地板球场、白色场线、蓝色禁区以及现有标注。逐句草稿默认白底灰边，仅焦点进入该卡编辑时使用浅灰底和黑框；其他卡保持白色。Agent 表单使用白卡加黑色顶边，普通状态说明采用灰色，错误提醒沿用红色。用户描述的比赛卡、四项比赛指标、赛前备稿与聊天气泡是视觉参考，仅在产品已有对应能力时应用。本次不新增聊天、示例比分、假 LIVE、赞助商或模型调用能力。

**功能保全：** 三个主工作区、归档球场映射、视频选择、导入、视频库、保存、撤销、四个球员处理步骤、全部画布工具、逐句解说、配音、成片与下载入口保持。移动已有 DOM 元素，保留 ID、事件绑定和面板实例；未新增另一套实现。没有把「打开视频」改名成语义不同的「新建解说」。

## 对比度与边界

纯色组合计算：近黑／白 18.74:1、次要灰／白 6.05:1、白／蓝 9.55:1、黑底灰字／近黑 7.85:1。亮红／近黑 4.39:1，仅用于大号品牌字。这些是色值计算，不是完整页面无障碍认证。

布局移动不更改视频坐标、球场投影、数据结构、接口、审核含义、模型策略、草稿保存或成片生成流程。所有按钮仍由原有业务逻辑决定可用性。本机预览不代表云端部署。
