# 人工战术制作：从打开视频到 MP4

更新：2026-10-05，Etc/UTC。适用于本轮 006 实现后的现有工作台。基础流程不需要 AI、球员 ID、JSON 或 2D 准备。源码核实见 [Task 0](manual-tactics-workbench-task0.md)，实际验证与限制见 [验收记录](manual-tactics-workbench-acceptance.md)。

## 1. 打开视频，建立画布

1. 打开已启动的工作台。更新代码后重启原服务并刷新页面，避免仍使用旧模块。
2. 点顶部 **「打开视频，人工制作」**，选择本机视频。工作台读取视频的真实帧时间，兼容 MP4 保持字节；其他格式会生成播放副本。处理完成直接进入「战术制作」，不运行检测模型。
3. 空白视频点 **「建立画布，开始手工标注」**。已有草稿会恢复，直接继续编辑，不要重新建立快照覆盖它。
4. 默认中央是视频。无映射时会显示 **「固定画面标注不会随镜头贴地移动」**。已有可用映射时，视频上点击会逆映射到球场坐标，导出随镜头投影。基础制作不必打开 2D。

「导入并识别球员」仍是原来的识别入口；本次基础人工流程使用旁边的新按钮。

## 2. 先设置时间，再绘制

视频下方 **「原片时间（秒）」→「定位」** 用于找画面；也可以拖「原片定位」滑条。**「原片播放」** 不插入讲解暂停，便于观察动作。

在画布下方的 **「新标注区间 · 原片时间」** 填开始、结束，例如 `1`、`5`，离开输入框后确认下方显示 `1.000—5.000 秒`。也可用两个区间滑条或「当前画面设为起点 / 终点」。输入会吸附到真实 PTS，并显示实际使用值；源视频不是固定 30 fps。

再选择工具：

| 工具 | 视频上怎么画 | 画完怎么改 |
| --- | --- | --- |
| 跑位 | 点起点，再点终点，自动完成一条可弯曲的箭头 | 拖两端改位置；拖蓝色主弯曲柄改弧度；拖线条整体移动 |
| 传球 | 点传球起点、接球终点 | 方向虚线箭头；支持同样的弯曲调整，默认完整显示至结束 |
| 挡拆标记 | 点掩护位置 | 拖中心移动；拖蓝色旋转柄或用右侧左转 / 右转；调整大小 |
| 更多标记 | 展开后可选黄色圆点传球、重点球员圈 | 原独立工具保留；没有轨迹时，在可选关联里选「静态圈（不跟随球员）」 |

没有新标注区间时，绘制工具会提示先设时间，不会默默使用整片。可以连续使用同一选区画多个对象；每个对象复制自己的独立区间。

未完成时按 **Esc** 取消。选中后的名称只用于编辑，不进入成片。重叠难选时，点下方时间条左侧的对象名称；不在当前显示区间的对象会定位到其参考画面。

## 3. 修改单个对象及路线效果

选中对象后，右侧出现 **「动作时间 · 原片」**（跑位/传球）或 **「显示时间 · 原片」**（挡拆/圈）。修改开始、结束后点 **「应用时间」**。这只改当前对象；两个端点也可填入当前画面。

下方每个对象有独立时间条：拖中间整体平移，拖两端改变区间。中间校正点按源时间平移或等比例重定位；整个拖动可以一次撤销。非法范围会就地提示，原对象保留。

跑位默认 **「随动作变短」**：已完成部分从起点消失，保留原曲线后半段，终点及到达方向稳定；过短时整体淡出。右侧「播放时的路线」可切 **「全程保留」**。这是按源时间裁短，不是自动跟踪球员。

复制、删除在画布上方的选中操作条。**撤销 / 重做** 在顶部；快捷键为 Ctrl/⌘+Z、Ctrl/⌘+Shift+Z（或 Ctrl+Y）、Ctrl/⌘+D、Delete。输入框中的文字删除不会删除对象。想单独改两个弯曲手柄，可展开右侧「精细曲线与样式」。

## 4. 添加讲解暂停点

1. 定位原片目标画面，例如 `1` 秒。
2. 在下方点 **「在这里暂停讲解」**。时间轴出现暂停标记，展开当前暂停属性。
3. **「额外停留（秒）」** 默认 `2.5`，包括停稳、绘制、看清的全部时间；新暂停最低 `0.9` 秒。多个对象共用一次暂停，不重复增加时长。
4. 在 **「本次展示」** 勾选已有对象；或保持当前暂停画面，设置新区间并直接新画，对象会自动关联该暂停点。右侧对象属性会显示「首次讲解」。
5. 拖暂停标记，或修改「暂停位置（秒）」即可改时间；也可「设为当前画面」。重复在同一帧添加会选中已有点。

暂停点必须早于或等于对象动作/显示起点。可以在 1 秒讲解将在 3 秒开始的传球：暂停期间提前画出，恢复后保持完整，到自身结束时间退场。已生效的无关路线保持当前剩余状态，后面的暂停不会重新展开它。

删除暂停点只解除关联，不删除对象，且可撤销。对象右侧也可 **「解除首次讲解关联」**；调整区间造成时间冲突时，可以先移动暂停点，或勾选「解除冲突的暂停关联」后应用。暂时不需要暂停时点 **「结束本次讲解编辑」**，接着独立绘制。

## 5. 校正移动节奏

1. 选中跑位 A，定位到动作中间，例如原片 `3` 秒。
2. 展开右侧 **「校正移动节奏」**，点 **「此刻走到这里」**。
3. 在淡色完整路线附近，点击球员此刻对应的路线位置。系统保存源时间与进度；不用填写百分比。辅助线不进入成片。
4. 列表中可以「定位 / 改位置」、修改时间后「改时间」、或「删除校正」。端点固定为开始 0、结束 1；中间点不能让进度倒退。

修改形状会保留校正比例，请复查节奏。如果球员明显不在路线附近，应修形状或拆成另一条动作；校正不能解决镜头运动。

## 6. 保存、看成片、下载

1. 点顶部 **「保存」**，确认显示 **「已保存 · 版本 …」**。浏览器会保留自动草稿，显式保存还写入本机服务。
2. 点 **「成片效果预览」**。工作台先保存当前版本，再通过正式编码链路生成 MP4；等待真实进度完成后播放。
3. 检查：停稳 → 本次对象逐步绘制 → 停留 → 恢复 → 跑位裁短 → 淡出 → 下一暂停。预览播放器显示的是成片时间，原片定位输入仍是原片时间。暂停成片播放器后可继续在原视频编辑。
4. 修改后，旧成片会标为旧快照；需要重新生成。输出信息包含保存版本与内容摘要。
5. 点顶部 **「导出 MP4」** 进入「保存与导出」，点 **「生成成片 MP4」**（已有当前结果时显示「已生成当前成片」），再点 **「下载成片 MP4」**。播放器与下载使用同一文件。当前链路为静音、30 fps。

保存失败显示「保存失败 · 草稿保留」；编码失败也不会删图形。修正提示的问题后重试，不必重画。版本冲突时先保留当前浏览器草稿，核对其他会话保存的版本，不覆盖它。

## 一遍完整练习

使用至少 8 秒的视频，时刻仅用于练习：

1. 定位 1 秒，添加 2.5 秒讲解暂停。
2. 保持这帧，新标注区间 1–5 秒，画跑位 A，拖弯曲柄。
3. 新区间 1–3.5 秒，画跑位 B。
4. 新区间 1.5–3 秒，放挡拆；新区间 3–4.2 秒，画传球。四对象应显示关联第一次讲解。
5. 定位 3 秒，选择 A，用「此刻走到这里」点路线大约三分之二的位置。
6. 定位 5.5 秒，添加第二个 2.5 秒暂停，画 5.5–7.5 秒跑位 C。
7. 看成片预览；修改 B 的结束时间、删除挡拆并撤销；保存刷新，核对 5 个对象、2 个暂停与 A 校正。
8. 正式下载 MP4。只有这两次暂停时，时长应约为原片加 5 秒，允许输出帧取整。

旧稿仍可读取。V1 草稿想使用新秒级控件时，在「坐标与高级画布」点明确的迁移按钮，它会保留迁移前浏览器副本；真实历史草稿迁移的浏览器操作本轮尚未验证。认可 005 原稿、归档脚本和成片未覆盖。移动映射回归本轮使用合成素材，真实比赛镜头精度需要另行核对。
