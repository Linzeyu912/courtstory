# 战术标注动态跟随与动效

## 解说绘图的路线覆盖

绘图开始时提供最多 7 张节点窗口概览帧，包含窗口两端、锚帧和前后中间帧，保留其余取帧额度供局部核对。对已观察到的持球推进、上提切入、掩护后移动和防守跟随，优先用独立路线表达；多人移动明确时以 2–4 条相关路线为覆盖目标，不对静止或遮挡节点强制凑数。

匿名主体可以用 `entityId=null` 与独立 `subjectId` 生成参考帧路线，缺少姓名或跟踪绑定不是省略路线的理由。当前完整动作允许包含锚帧之前的移动；路线各点需参照可见球场线统一到锚帧视角。随后的已观察动作仍使用虚线，不能把镜头移动或传球当成球员跑位。独立视觉审核继续核对主体和几何。

阿门训练片原云端候选为 5 个节点、21 个图形，其中 1 条路线、17 个位置环、3 个重点圈。这是本轮调整的对照样本，不代表新版本的生成结果。

V4 绘图候选进入 `adoptAgentCandidate` 时，如果 `entityId` 对应已有观测，且图形起点接近该球员的实际脚点，宿主自动启用跟随。路线还要求显示区间内存在可见位移。匿名或起点不匹配的图形保留参考帧行为，不改写旧稿的绑定。

- 路线：从当前脚点取剩余观测轨迹，显示层简化检测抖动后生成平滑曲线。有效球场标定存在时，先把各帧脚点转到球场，再投回当前镜头；没有标定时降级为画面坐标跟随，不能保证移动镜头下的贴地精度。
- 缺测、身份冲突、切镜：隐藏或截断，不跨缺口连接。跟踪编号切换处也截断当前采样段。
- 位置标记：原来的小叉统一改为脚下薄环。新绑定标记跟随脚点，有标定时使用球场透视。
- 绘制：按曲线长度逐步展开，箭头头部与当前绘制终点一致。掩护讲解依次显示薄环、掩护短杠、持球者路线、掩护者后续路线；后续路线的战术含义仍由候选决定，不自动认定为顺下。
- 时间：普通讲解默认绘制 0.7 秒，含掩护的讲解默认 1.2 秒，总暂停时长不变。显式成片编排仍可覆盖。
- 编辑：拖动跟随路线的控制点后切换为手工路线，避免播放时自动轨迹覆盖人工修改。暂停编辑展示原控制点，成片预览通过共享 SVG 渲染器查看动态效果。

实现入口：`player-review/tactics-motion.mjs`、`tactics-annotations.mjs`、`tactics-agent.mjs`、`tactics-production.mjs`。原始跟踪数据及其审核状态不变。

## 已确认的图二贴图样式

`tactics-paint.mjs` 统一提供画布和成片的 SVG 绘制样式：普通曲线箭头主体加粗为原线宽的 1.6 倍，使用浅色亮芯、颜色渐变和轻微光晕，移除深色硬描边；箭头尖端保持原位置，线身在箭头内部收口。虚线和圆点仍保留各自的间隔和含义。已有宽带曲线保持原轮廓，使用相同柔和配色及较淡的可配置边缘。

重点圈采用白青色发光边缘、半透明地面光晕及原有向上渐隐柔光，背景压暗由 30% 调为 14%；普通位置环保持较弱亮度。挡拆短杠沿用原方向与结构，改用浅金亮芯和柔光。

此次仅修改绘制样式，不调整观测数据、球员绑定、路线轨迹、缺测处理、绘制时序、选择命中和编辑操作。

人工标注完成后的画布、Agent 标注与正式导出共用 `renderAnnotationsSVG` 和这套贴图。手工虚线／圆点传球在落下终点前的鼠标预览也使用共享路线几何和绘制样式；控制点、选中手柄等编辑辅助仍单独显示。人工画布与成片的样式一致性覆盖跑位、虚线传球、圆点传球、重点圈、位置环和挡拆标记。

新成片与实际渲染图片保存在 `artifacts/tactics-style-v2/`。演示使用前述真实视频和同一套轨迹；为了展示重点圈样式，演示快照中持球人的普通位置环改为已有的 `spotlight` 类型，其显示区间沿用原区间。这是演示标注设置，不改变 Agent 的重点圈使用规则。
