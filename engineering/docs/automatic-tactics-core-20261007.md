# 自动战术核心修复与真实验证

2026-10-07，Asia/Shanghai。当前状态：实现已载入本机工作台；本轮完整视频重复验收未通过，模型调用反复中断或无响应仍未解决。不能将代码回归通过等同于自动生成已经可靠。

用户目标是一次提交完成主要战术标注，人工只核对具体例外。主流程是原视频观察、多人真实动作路线、持球人圈、独立核对与定点纠正。仅提供手绘工具和错误提示不满足该目标。实施依据见[本轮计划](plans/2026-10-07-automatic-tactics-core.md)。

## 已修复并复核的故障

- Windows 进度文件占用曾中止正常模型进程。大型预览改为摘要校验的独立文件；进度写入受阻不会杀死推理，必要保存失败单独报告并保留已收到结果。
- CLI 已返回完整最终消息和完成事件，结果文件尚未落盘时仍被超时杀死。现在严格校验完成事件、最终 JSON 和禁止工具的约束后保留结果；部分消息不算完成。
- 模型不再同时编写全量工作台文档。它输出紧凑视觉事实，程序编译原生文档；输入为同源高清原图，预览复用同一帧，不重复解码或拿缩略图替代审核证据。
- 首次模型的 `move` 或人物连续性声明不是已确认事实。基本来源和引用检查通过的三类语义缺项可进入独立审核；未审观察不能提前采用。具体路线只有通过逐帧人物、球权、方向、相机参照的核对才进入可展示候选。
- 路线审核只证明对应证据帧，不顺便确认该人在其他帧的身份。内部逐条授权绑定完整事实、来源与审核；模型 JSON 和保存的普通 JSON 不能自称获得授权。
- 已核对的图形与观察在定点修正中冻结。修正采用小型受控修改集合，随后重新审核及原生校验；不能删除路线、改成静止或缩短时间来冒充修复。
- 首次提案只有一帧却自称移动，保留原动作声明、原观察与具体缺证例外，不逼模型补出不存在的路线。独立审核明确看到的漏运动与这种未核实提案分别记录。
- 修改球员姓名不再使同一来源的有效匿名像素标注全部失效。旧失效图形、实体跟随图形、贴地图形及来源/时间/切镜变化仍不会被自动重新确认。
- 真实结构化审核报告及媒体凭据随采用后的草稿保存；没有浏览器任务句柄也可只读查看对应疑点并跳到原画面，不伪造任务或开启采用/重试。
- 已加入本地court48和独立地板线支撑的保守终点冲突检查。只有大幅矛盾才移除该路线的可展示许可，并将具体相机疑点送回同一轮局部patch和复审；不会修改原事实，不把粗矩阵当作精确坐标授权。原图摘要、尺寸、切镜和权重校验保护缓存；取消、30秒或更短剩余预算保护独立进程。
- 视频画布按可用全宽保持原片比例，不再被720像素视口硬压成约395×222；2D视图保留原高度范围。疑点按阶段和人物聚合，完整审核依据可展开。
- 某一阶段审核后没有可编译动作时，不再提前丢弃整片审核和后续阶段。完整报告与修正需求先保留，无动作阶段继续等待核对；全部仍无有效内容时保持失败，不能用全未知通过。
- 相机反证绑定具体路线几何及原图来源持久保留。只改说明文字不能撤掉已发现的几何冲突；新检查暂不可用时也不能恢复错误许可。
- 视觉审核按原参考画面的动作示意判断同人、方向、地板区域及大致终区；单纯没有像素或米制测量不再等同于无法确认。跨人、反向、错误终区及无法解释的镜头位移仍拦截，质量规则没有改成只看方向。
