# 球员标定：点选、关联与识别

更新：2026-10-10（Asia/Shanghai）。人工关联支持看画面设置范围及整条 T 编号归并；下方带日期的验证记录保留当时结果。

## 怎么修改画面中的人

暂停在能看清人物的一帧，直接点击人物框。右侧会显示当前人物、对应球员选择和明确的关联按钮。例如选择“球员 10”，点击“将 T60 关联到球员 10”。不需要先进入“改成谁”模式，也不需要填写帧号。

按钮旁显示本次影响的时间范围。默认仍选择当前连续观测片段；其他无关球员的单帧确认不会把当前人物的范围切碎。关联前可直接选择：

- **当前连续段**：用于修改这一段明确的错误归属，保留其他时间段。
- **从当前帧往后**：归并这个 T 编号从当前画面开始的后续真实观测。
- **整个 T 编号**：归并这个编号的全部真实出现帧，包含当前画面之前。

不用输入具体秒数也能选择一段：拖动底部视频进度到开始画面，点击“当前帧设为起点”；再拖到结束画面，点击“当前帧设为终点”。“跳到起点 / 终点”用于回看边界。移动播放进度时保留已选 T、目标球员和待应用范围；需要精确输入时再展开数字时间选项。

上述操作先预览，点击关联按钮后才写入，支持一次撤销。后续／整 T 归并沿用已有人工纠错的优先级，缺少观测的帧保持空白，不自动填位置或把全部帧标为已人工核对；发现编号中途认错人时，先选“当前连续段”，再调整起止画面并关联，明确纠正有限区间。有限段纠错若涉及其他球员的重叠归属，会先显示受影响帧数。

这里的“球员 10”是标注槽位；球衣号码另标为“球衣 #30”等，不是同一个编号。T60 是检测追踪号，也不能证明整条轨迹始终属于同一人。

切换时间保留正在编辑的关联范围，视频还在定位时不能应用旧画面修改；点击另一人物或取消修改可结束当前选择。裁判可用“不是球员”排除当前范围，漏检可用“补漏人”按起止画面补一段脚下点。补位置不等于确认身份或接地。

窄窗口（900px 及以下）使用上方完整视频、下方操作面板，点人物后自动滚到修改入口；工具不再覆盖视频右侧。宽窗口保留左右布局。

## 怎么使用建议

在“已有建议与人物续接”中，已有机器建议和续接建议显示时间范围，可先预览，再直接采用。无需重新输入起止帧。已有机器绑定建议采用后显示“已关联”，撤销后恢复可采用状态；原机器记录保留作来源证据。

采用范围受真实观测和人工冲突检查约束，不把整段自动标成逐帧已确认。与已有人工记录冲突、缺观测或过期结果会给出提示；人工仍须判断选中的是不是正确的人。

## 怎么识别球队、号码与姓名

1. 视频载入后，Agent 从比分牌自动识别本场两队。结果可在“修改本场球队”中修正，失败可重试或人工选择。
2. 人工选择视频赛季。
3. 点击画面人物，再点击“识别选中球员”。读取选中人物的球队和号码，按赛季查询球员名单；唯一匹配会预选，人工核对后点“确认身份”。

未关联人物可以先识别，但须关联到一个球员槽位后再确认姓名，结果不会写入另一个先前选中的球员。人工正在修改球队、号码或姓名时，迟到的识别结果不会覆盖这些输入。自动识别两队也不会擅自认定红蓝标注组的球队归属。

看不清号码、球队不明或没有名单匹配时，可以直接填球队和号码，点击“查找球员”。技术错误收在“识别详情”，不需要用户理解 OCR 依赖。主要识别路径使用现有视觉模型；没有安装新 OCR 依赖或更换 YOLO。
