# 检测器、跟踪器选择与视频布局

更新：2026-10-03，Asia/Shanghai。分类提交与同步结果见[发布交接](../../handoffs/Linzeyu912/2026-10-03-1630-workbench-updates-publication.md)。后续界面调试使用 Codex 内置浏览器，人工核验继续使用本机草稿。

## 选择与运行

顶部和视频库分别提供「YOLO 检测器」「跟踪器」，推荐项右侧显示小号「推荐」标记，不再用成员姓名命名推荐。默认沿用原 `team-stable` 路线。

| 检测器 | 跟踪器 | 结果标识 | 说明 |
|---|---|---|---|
| YOLOv8n · 篮球（E-BARD） | BoT-SORT · 外观续接 | `team-stable` | 默认；保留篮球优化、ReID、稳定显示 |
| YOLOv8n · 篮球（E-BARD） | ByteTrack | `ebard-byte` | 新组合；与原 `ebard` 参数结果分别保存 |
| YOLOv8s · 通用 | BoT-SORT · 外观续接 | `yolo-team` | 新组合；原生外观特征、篮球修正、稳定显示 |
| YOLOv8s · 通用 | ByteTrack | `yolo` | 原通用路线 |

更改下拉框只选择组合。已有结果时点击「应用组合」切换；缺少结果时点击「处理并应用」，显示处理进度，完成后自动打开。视频库每行同样按当前两个选择项打开或处理。已裁切的工作台视频可以直接重新处理，无须再导入一次。

检测器影响逐帧候选及类别：篮球权重使用 `player`，通用权重使用 `person`。跟踪器影响观测关联、T 编号和断轨续接。不同组合可能产生不同的候选、关联和后续战术输入；本轮没有做模型精度排名。

历史 `original`、`ebard`、`baseline`、`low`、`reid`、`optimized` 等结果在左侧「模型说明与视频来源 → 已保存的结果」保留，不重命名内部 ID 或覆盖旧指纹。历史低阈值 / 基线未开启 ReID，不能被当成当前外观续接组合的相同参数结果。来源区给出实际参数，顶部按钮只会明确应用或处理新的组合。

## 后端约定

- [组合目录](../configs/tracking/workbench-models.json)是前端选项与后端运行计划的共同来源。`GET /api/library` 和 `/api/video-library` 返回 `modelChoices`。
- `POST /api/video-library/process` 接受 `id`，或已加载视频的 `sample`，以及 `detector`、`tracker`；若同时提供 `variant`，必须与组合一致。不接受客户端文件路径。旧 `variant` 请求兼容。
- 同一来源 SHA 的不同组合分别保存，保持 GPU 串行；没有自动跨模型复制 T 编号或人工确认。
- `process_local_video.py` 按组合选择权重、跟踪参数和稳定显示，只验证本次所选权重。`basketball_run.py` 将检测类别选择与跟踪 profile 分离，在 metadata 的 `model_selection` 中记录真实选择。
- 旧路线运行参数保持。新组合复用当前 ByteTrack / BoT-SORT 配置；通用检测尺寸 640、NMS IoU 0.7，篮球检测尺寸 704、NMS IoU 0.5。
- 变换模型后球场与人物仍需核对，战术继续绑定各自来源快照，不静默改写已有审核。

## 布局与验证

- 中间保留视频、候选框及交互画布；视频与叠加共用同一矩形。
- 图例、显示开关、检测诊断、审核颜色说明、覆盖统计与模型来源移到左侧「画面说明」，独立滚动，可收起。
- 右侧保留初筛、球员标定及其他操作；底部保留播放、帧定位、人物和标定时间轴。
- 窄窗口默认收起说明栏，可临时展开。没有裁切图片或改变标注坐标来放大画面。
- 两个新组合均经内置浏览器完成真实 143 帧 GPU 处理并自动打开。核对权重、检测类别、跟踪器、ReID、稳定显示及不同指纹；错误组合返回 400，原视频 SHA 不变。
- 同一 1706×960 CSS 窗口的初筛视频由约 922×519 增至 1061×597；右侧栏保留。另检查 960 像素宽窗口无页面横向溢出，标注页视频和 overlay 的位置、尺寸一致。
- 测试与截图在本机忽略目录 `artifacts/model-layout-20261003/`，最终结果见[本轮交接](../../handoffs/Linzeyu912/2026-10-03-1545-model-selection-layout.md)。
