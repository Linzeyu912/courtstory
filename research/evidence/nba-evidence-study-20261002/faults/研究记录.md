# 受控故障注入：局部告警、自动修补与持续拒判

日期：2026-10-02。只读使用本机仓库四个 `team-stable` 快照；全部实验产物在本目录。没有运行跟踪器、改动 ByteTrack、修改生产文件或提交推送。

结论：局部异常告警可以发现部分故障入口，却不能证明后续身份恢复可信；全轨平滑会改变正常运动，短缺口插值也不能自证正确。保留 raw 并分项标明可用性有必要，但把所有异常升级成持续身份拒判会大幅损失可用率。

## 范围与口径

- 14 个可解析合成场景，540 个期望位置槽/常规场景；真值由解析式独立生成。包含几何突跳、重复、缺轨、远距/相交 ID 交换、健康相机共移、切镜、重复 PTS、静默标定尺度错误。合成框只用于实验，不冒充真实视频标注。
- 四份真实模型输出共 9,937 个 track 观测。每段按确定规则取靠近中点、连续存在的轨迹，分别注入六种故障，共 24 次单独对照：突跳、重复、三帧缺失、五帧 ID 交换、单帧共同平移、重复 PTS。注入坐标及原文件 SHA256 见 `fault_results.json`。
- 真实输出不是独立真值：只报告已知注入的告警、原始观测改动、可用率及额外告警。自然误报率、真实身份精度明确置为 null；不根据这些实验宣称模型准确率提升或下降。
- 使用 `source_frame_pts × source_time_base` 的时间差和框底边中点。后者是图像代理位置，未经验证为真实接地点。LAL 快照第一行 `time=0.12`，等于原始 PTS 秒；不能一概当作归零后片内时间。
- 事件检出窗口预先固定为起点至起点后 3 帧。一个 jump 的两条异常速度边只算一个事件。表中“检出”表示症状触发，不表示原因归属正确；长 ID 错段另报逐槽覆盖。
- 合成误报是已知健康观测被标记的数量，包括重复候选旁的真实框和交会前轨迹。这反映 review 的附带成本，不等于每条复核理由都不合理。缺失槽、重复输出和已观测槽分别计数；不合并成一个“准确率”。

## 第一轮：固定规则对照

速度基线门限为 600 px/s；它不是 NBA 物理速度上限。分别报告只告警、异常点置空后最多三帧插值，以及再加居中三点平均，避免把插值和平滑的影响混在一起。review 策略增加重框/近距离歧义、PTS 有效性、重现缺口和共同运动提示，始终保留原始位置，不补缺失点。共同位移只标为原因未明，不能认定是相机运动。

| 合成场景 | 实测结果及含义 |
|---|---|
| 单点 +120 px 突跳 | 所有策略检出；速度同时误标下一健康点。插值在这条特意构造的直线真值上恢复正确，说明自动修补在满足假设时有价值 |
| 五帧重复候选 | 速度漏掉全部 5 槽；review 标到 5/5，并连带标记原轨迹 5 槽；未证明哪个候选应删 |
| 三帧直线缺口 | 插值准确恢复，review 留空。两者首次识别均等到重现帧 |
| 相同可见观测的隐藏弯曲缺口 | 插值仍给出同一条直线，但 3 个新增位置均错误，故障区 RMSE=20.41 px；review 留空。两场景观测完全相同，真值不同 |
| 远距 ID 交换后持续 50 帧 | 事件立即触发，但局部规则只覆盖 2/100 错误身份槽；其余 98 槽仍被“未告警”放行。平滑还使 2 个原本正确位置受损 |
| 同队交会后 ID 交换 | 速度漏掉 98/98；局部 review 覆盖 8/98，同时标记 10 个健康槽，剩余 90 个错误槽继续放行 |
| 干净加速/转向 | 无速度故障；全轨平均改变 88 个本来精确的位置，整体 RMSE=0.081 px。数值虽小，足以否定“越平滑越真” |
| 健康快速相机共移 | 48 个正确观测超过像素速度门限；自动插值无法跨八帧高速度段，删除全部 48 点。review 同样需复核 48 点，但原始证据保留 |
| 两镜头坐标各自正确、ID 被复用 | 自动插值误改 6 点，加平滑误改 18 点；review 保留正确图像坐标并提示共同运动未明。仅有轨迹不能把此症状认定为切镜 |
| 重复 PTS | 时间异常应阻止速度声明；自动位置插值反而改坏 6 点，加平滑改坏 18 点 |
| 错误的 2 倍米制尺度 | 所有几何规则均无法发现“仍声称已验证”的静默错误。若来源明确未验证，review 拒绝米制声明；这依赖真实来源状态，不是从轨迹恢复了尺度 |

四段真实输出的六种注入，局部 review 在预定窗口触发 24/24 次；纯速度 16/24、插值策略 20/24。这里包括容易发现的人工错误，不能外推到自然故障分布。五帧 ID 交换虽四段均触发，局部规则每段仍只覆盖 2/10 个被换身份的槽。JSON 另列注入前已有告警数与真正新增告警，避免把原有告警当作注入收益。

## 第二轮：身份不确定性是否应持续

新增“在局部风险后持续拒判该 ID，直到出现独立身份锚点”的保守对照；本实验没有供给锚点。远距和相交 ID 错段均达到 100% 拒判覆盖，接受的已知错误位置降为零；这没有纠正任何身份，只是停止使用这些片段。

| 真实样例 | 原观测 | 局部 review 告警 / 策略放行覆盖率 | 持续拒判告警 / 策略放行覆盖率 |
|---|---:|---:|---:|
| 004 | 1,867 | 144 / 92.3% | 1,270 / 32.0% |
| 005 | 1,324 | 143 / 89.2% | 845 / 36.2% |
| 006 | 4,357 | 384 / 91.2% | 3,908 / 10.3% |
| LAL–MIN | 2,389 | 79 / 96.7% | 1,834 / 23.2% |

“策略放行覆盖率”不代表身份正确；review 挡住告警槽，而 naive 对所有仍输出的位置放行，包括被告警位置，故不能把此指标解读成各策略统一的未告警率。持续策略甚至在健康相机共移中误拒 294/540 槽，使放行覆盖率降至 45.6%；不能直接部署这种全类型永久传播规则。正确后续是分别维护位置、身份连续性、时间、相机与米制标定状态，并用有来源的锚点按区间释放相应维度。

## 第三轮：把显示、身份和运动分开

仅追加六个合成代表场景，未重跑 24 次真实注入。初始身份锚点在本轮合成实验中假定已由独立来源确认；该假设不能移植到四段未经确认的真实模型输出。前轮两种 review 本来就保存全部 raw；以下是“如果界面把总放行资格也用于控制显示”的反事实比较，不是实际恢复此前删除的观测。

| 合成场景 | 假设总资格同时控制显示 | 分项门控保留 raw 显示 | 获准身份关联 / 同 ID 坐标误差超过 1 px |
|---|---:|---:|---:|
| 远距 ID 交换 | 440/540 | 540/540 | 440 / 0 |
| 同队交会交换 | 432/540 | 540/540 | 432 / 0 |
| 镜头转换疑点 | 240/540 | 540/540 | 240 / 0 个位置关联误差；未证明跨镜头同人 |
| 重复 PTS | 240/540 | 540/540 | 540 / 0 |

远距和交会交换的原始位置集合经逐帧无身份匹配，均仍与真值位置集合一致；受损的是姓名/身份与轨迹的关联。同 ID 坐标差只是几何代理，零误差不保证身份正确；另按这两个场景明确注入的 100/98 个身份错误标签评估，获准输出的错误身份槽均为 0。匿名显示可以保留全部候选，同时禁止依赖未知身份的叙述。重复 PTS 则无需撤销已知身份锚点，但须同时禁用异常时间点前后两条运动边：本例正好阻断全部 12 条错误时间依赖边，仍保留 522/534 条时间有效且身份可用的运动边。

这只是信息使用权限分开后的保留效果，不是新增精度：单点突跳场景也显示全部 raw，却仍有一个错误位置候选，必须显式带待复核状态。共同运动的真实原因仍未知；切镜状态和真实相机/标定证据没有由此自动恢复。结果见 `capability_results.json`，脚本为 `capability_ablation.py`，五项针对性核验通过。

## 信息损失、时间与可识别边界

在未注入的四段真实输出上，自动插值改变 549 个已有位置、删除 109 个已有位置、补出 83 个新位置；加全轨平均后，改变 9,475/9,937 个已有位置，删除数和新增数相同。这里的改变不是已证实伤害，但如果将其作为唯一数据源覆盖 raw，会丢失原观测与推导值的区别。review 两种策略均保留全部原观测，改变/删除/补出均为零；零改动是设计属性，不是更高精度的证据。

局部几何告警不需要未来帧。三帧缺口首次判断需要重现：四段实测延迟分别为 125.16、100、100、120 ms。居中平滑额外依赖一帧未来数据；插值需要下一个保留端点，最多等待四个帧间隔。脚本总运行时间只是该本机离线分析开销，不是端到端直播性能。

仅用三个预先指定门限检查告警量：300/600/1200 px/s 分别在四段产生合计 2,300/658/134 个已有观测告警。没有自然真值，不能据此选“最优阈值”；同一像素门限还随画面尺度和视角改变。

米制权限对照也属于假设：像素基线没有标定门控，实验将其权限记为允许，并未真的让它生成米制输出。未验证状态下 review 不允许米制声明，测的是来源约束是否被遵守，不能冒充标定错误的自动识别能力。

`identifiability_witnesses` 给出可复算的观测等价反例：①同队两人的穿过与遮挡中转身，可产生完全相同的框与输出 ID；构造使用三次曲线，速度和加速度连续。②固定相机下全员共同平移，与静止球员加相机平移，产生相同图像轨迹。③米制尺度不同，仍可产生相同图像轨迹。没有独立身份、球场/背景或标定证据，几何算法不能同时保证低误报和低漏报；提示未知比编造确定原因更可检验。

## 复现与核验

```powershell
& $python -X utf8 '.\faults\run_fault_experiments.py' --repo $repo
& $python -X utf8 '.\faults\verify_fault_experiments.py' --repo $repo
& $python -X utf8 '.\faults\capability_ablation.py'
```

结果：`fault_results.json`；校验：`validation.json`。校验包括两次完整重跑除运行时外语义一致、八份输入 JSON/metadata 哈希一致、策略不读取注入位置或合成真值、两种 review 原位置逐值保留、隐藏弯曲缺口误差与闭式解一致、观测等价反例成立。

边界：仅四个片段、确定故障位置与有限场景，没有置信区间、自然故障准确率或通用阈值结论。尚未验证跟踪证据字段矛盾、真实脚点、人物外观、背景运动估计、真实镜头边界与人工身份锚点；这些应与本实验分开评估。
