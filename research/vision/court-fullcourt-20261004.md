# 全场联合标定开发与复验

日期：2026-10-04，Asia/Shanghai。用户要求先解决跨中场的球场标定，再分别做好人物轨迹与脚下点，最后才联合量化到 2D。

本次保留全部既有检测、人物身份、脚下点与原始标定。新增独立离线候选流程，没有替换工作台默认后端，没有提交或推送。实现和运行入口见[工程说明](../../engineering/docs/court-fullcourt-calibration.md)。

## 输入与方法

- 用户指定的 36 秒 DAL–HOU 连续摇摄片段，1552×872，30 FPS，1080 帧；源文件 SHA-256 为 `994c43388a2c31a44fcc8259bba1d4d71abab0dd439aed46da09c22e14012b23`。
- 来源登记入口：`data/videos/uploads/2026-10-04/labels/004.json`。赛事日期和赛季不在本轮确认范围内。
- 沿用[上一轮](court-generalization-20261004.md)的四套检测 / 标定缓存与已知数字变换：原片、降分辨率后模糊压缩、额外缩放平移、降亮度。仍用原 Court48 权重；没有训练新模型，也没有改变 E-BARD YOLOv8n。
- 把两端禁区的语义点线、中线观测和地板纹理运动放进同一全场坐标解；不再分别定义左右半场后直接拼接。
- 中圈模板和可见圆弧残差已加入；此片中圈被大型队徽遮挡，没有可信圆弧观测。本片不能用来验收自动识别中圈，实际约束来自两端禁区、可见中线和地板运动。
- 相机关系图不连通的小段保留未注册状态；逐帧必须有测量到的地板运动。原始场地点、图像对应、矩阵、排除原因和优化终止状态完整保存。
- 最后对可见投影跳动帧做独立双向光流核验，从前后联合关键帧投到当前帧。两侧证据相互吻合且都与当前异常矩阵不符时才修复；没有改变球员轨迹，没有补齐缺失矩阵。修复 5 / 1 / 8 / 9 帧，共 23 帧，原候选保留在 `before-motion-audit/`。

### 可见中线抽查

在两次经过中场时各取 3 个非求解关键帧（195、211、225、705、721、735），从原始画面可见中线读取 12 个点，记录[目视参考与来源](court-fullcourt-20261004-line-checks.json)。这些点只进入报告，不进入标定。

原片的点到投影中线距离：中位数 **96.45 → 4.08 像素**，P95 **167.42 → 7.27 像素**。参考由 Agent 目视读取，估计读取不确定性约 ±5 像素，尚未用户复核，不能宣称真实定位精度就是 4 像素。

同样参考经过已知图像增强变换后，模糊 / 缩放 / 降亮度版本的中位距离约 1.22 / 1.24 / 14.99 像素。前两个数低于目视读取不确定性，不能据此排名或声称亚像素级精度。降亮度版本没有检出满足现有对比度门槛的中线，依靠两端和运动传播，中场还有可见偏差。

### 增强一致性（不是准确率）

在原片可见球场内的固定图像网格上，按已知增强矩阵比较原片与增强版本的地面坐标。运动修正后，模糊、缩放、降亮度版本的差异中位数 / P95 分别为 0.226 / 0.851、0.0209 / 0.1239、0.1175 / 0.3437 米。这种比较只判断两套流程是否一致，不能证明两者的坐标都正确；运动修正不在上述 6 个原片目视抽查帧。

## 验证与限制

- 8 项已知几何 / 切镜 / 反转 / 空白场地 / 圆弧 / 实际合成地板光流测试通过。包括给合成相机矩阵插入 50 像素异常，确认基于真实光流修复，且原缺失帧不填补。
- 输入视频与 16 个读取缓存逐一核对哈希；4320 个逐帧记录的时间戳和所有有效矩阵的可逆、凸性、往返误差检查通过。两段成片均完整解码 1080 帧，30 FPS / 36 秒、H.264 / faststart；播放器 206 字节范围、跳转及真实浏览器播放通过。验证入口是 [`validate_fullcourt_benchmark.py`](../../engineering/scripts/validate_fullcourt_benchmark.py)。
- 8 次联合优化中有 7 次达到 100 次迭代上限，1 次满足数值收敛条件；终止状态未隐藏。所有矩阵继续标为待复核，不把有限迭代、线缘残差或高覆盖率当作精度验收。
- 这是同一个视频上的算法开发与复验，不是独立留出测试集；三个增强版本不构成三场新比赛，也没有完成跨场馆 / 机位 / 切镜泛化验收。
- 当前自动入口只处理同侧机位的连续镜头。显式切镜不得跨越，物理篮端、队伍进攻方向仍未验证；中圈可见圆弧的自动语义提取仍待后续真实样本。
- 下一步先由用户检查球场专用视频，特别是半场 → 中场 → 另一半场及返回过程。随后分别验收人物轨迹与脚下点，最后再做人物 / 球的 2D 联合量化和展示平滑。
