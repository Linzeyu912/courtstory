## 修订与失败

1. `001-memes`、`002-memes`、`001-expression`、`002-expression`为v1探索，输出整体偏保守。
2. `001-memes-v2`、`002-memes-v2`放开表达后均在两次调用内未通过时间预算，失败记录保留；没有覆盖原稿。
3. `001-memes-v2-budget`、`002-memes-v2-budget`加入预算提示后通过，但暂停句仍偏长，因此v3同时约束暂停扩写。
4. [工作台首次失败](workbench-budget-failure.json)暂停句粗估6.48秒、原预算6.36秒；严格按小数拒绝不适合粗估用途。v3.1允许原暂停句估时加0.5秒（下限4秒），仍防止长段子扩写；后续真实工作台调用一次完成。
5. 文字估算是提示与早期筛选，不能代替实际配音时长，更不能用结构校验保证所有事实正确。
