## 新主线与边界

- 原视频与真实 PTS → 专业检测／跟踪 → 离线联合身份与定位修复 → 稳定逐帧球场映射 → 区分观测／恢复／估计／未知的 2D → 模型战术事件与图形 → 确定性投影／编码。
- 常规任务由后台自动选参考、建立／保存准备、校验、机器接受和渲染；人工只接异常片段，不能把每步等待点击采用写作自动完成。
- 原跟踪没有 row 不等于人物完全不可见。可见漏检重新定位产生带证据的候选，真不可见只能明确估计或未知；长缺口、切镜、身份冲突不能无条件连接。
- 当前 IdentityAgent 只匹配已有 T，Qwen 修正只接已有有限原始坐标；恢复漏检和遮挡估计要新增合同，不能简单删旧 guard。
- 当前单阶段服务、浏览器采用／保存不是统一自动 runner。需要持久 run、阶段依赖、质量门控、恢复和机器接受审计，机器接受不伪造人工确认字段。
- V3 当前要求非空图形、已保存准备与匹配证据；规划新增无有效战术／证据不足／部分结果，不能为满足 schema 造一条箭头。
- 模型 provider adapter 与第三方调用整条 workflow 的 API 分开；UI 和第三方使用同一 runner，不依赖模拟浏览器点击。
- 保存 raw outputs／manifest 可重放数据、几何与编排；重新调用模型不保证同输出，跨编码环境也不保证 MP4 位级一致。

## 官方来源与候选

- 核查 SportsMOT、SAM2／SAM3.1、CoTracker3、TAPIR／tapnet 和 KaliCalib 官方论文或作者仓库。分别作为关联、mask、点跟踪／可见性／不确定度、球场注册的评测候选，不代表已安装或已在本视频改善精度。

## 分阶段实施与验收

- M0：人工真值与失败分类、同片自动基线、两层 API 与数据合同。人工标注用于评测，不作为日常生产步骤。
- M1：单人／连续镜头自动身份与位置修复、camera gate、一次 submit 的小范围自动整链。
- M2：逐步到 3 人、10 人联合处理，评估错误自动接受、自动完成与人工接管比例。
- M3：深化多角色战术结构、时序／图形／投影验证和确定性成片。
- M4：provider adapter、持久 workflow API、manifest 重放与重推理、有限并发／缓存／安全合并。合同从 M0 定义，接通与验收后置。
- 遮挡评测使用清楚可见片段的控制遮挡／隐藏检测，与保留真值比较；模型输入不能泄漏目标未遮挡原图或真值派生的框、脚点和 2D 坐标。真实不可见不拿模型自填点验精度。
