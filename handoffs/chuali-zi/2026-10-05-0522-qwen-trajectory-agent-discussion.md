## 结论与依据

- 核心模型明确为 Qwen3.8-Max API，凭据名 `QWEN_KEY`；当前任务是讨论架构，不能据此直接实施或执行模型实验。
- Pi SDK 支持工具结果中的真实图片及工具执行后的下一轮调用；OpenAI 兼容层把图片放入追加 user 消息。可作为轻量候选，实际 Qwen 兼容性未验证。
- IG-VLM 对应帧拼图方法，单独不满足迭代 Agent；VideoAgent-tools 有 agent → tools → agent 及真实 view_frame，可借鉴证据循环。
- 地面映射须结合跳跃 / 接地 / 真实水平运动；跑跳不能锁坐标，空中地面位置回投不能要求贴着空中脚像素。
- 建议模型主动补证据、修改地面锚点和事件区间、看同步渲染后继续修正；数值拟合作为可调用工具，保留真实急停 / 转向。
